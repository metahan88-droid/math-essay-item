초안 에이전트가 문항 초안을 만들 때 갖춰야 할 전이성 5요건과, 초안의 성패를 가르는 수치 설계·검산 규칙이다. 초안을 쓰기 전에 읽고, 초안을 낼 때 이 문서의 판정 질문과 게이트 결과를 함께 반환한다.

전이성 5요건은 이 스킬의 기본 게이트(사용자 확정 정책)다. 전이의 학술적 필요충분조건이 아니라 이 스킬이 채택한 설계 점검표이며, T3~T5는 성취기준 성격(증명·통계·작도 등)에 따라 0단계에서 조정할 수 있다.

이 문서에 나오는 `lesson1_act`~`lesson5_act`·`item_intro`·`item_questions`·`item_cond`는 슬롯 JSON의 키 이름이다. 키 전체 목록과 각 키가 인쇄되는 자리는 `references/hwpx-build.md`의 슬롯 표에 있다. 예시로 드는 「피자 문항」은 두 판본이다 — **원판**(미디엄·라지·자이언트, 지름 24·30·36 cm)과 **네모피자판**(스몰·미들·빅, 한 변 21·28·35 cm). 아래에서 판본을 밝히지 않은 수치는 문맥의 판본을 따른다.

## 전이성 5요건

초안은 다섯 요건을 **모두** 갖춰야 한다. 하나라도 ✗이면 초안을 되돌린다. 판정은 초안 텍스트를 실제로 세거나 python3로 계산해서 한다. 눈으로 보고 "갖췄다"고 적지 않는다.

| # | 요건 | 판정 질문 | 통과 기준 |
|---|---|---|---|
| T1 | 학습 맥락과 다른 새 맥락 | 차시 계획의 활동 문장에 문항 소재어가 몇 번 나오는가 / 지우면 답이 달라지는 맥락 문장이 몇 개인가 | 0회 / 2개 이상 |
| T2 | 공식을 주지 않고 관계를 도출 | 학생 지면에 결론 관계식이 몇 개 인쇄돼 있는가 | 0개 |
| T3 | 오개념 진단 장치 | 자료에 심은 **수학적** 오류 주장이 몇 개인가 / 각 오류가 채점 요건에 1:1로 걸렸는가 | 2개 이상 / 전부 |
| T4 | 정답 유일·경로 복수 | python3로 끝까지 계산한 서로 다른 경로가 몇 개이고 결론이 몇 개인가 | 경로 2개 이상, 결론 1개 |
| T5 | 역방향 추론 | 「구한 값 → 그 값을 만든 조건」 방향으로 진행하는 요건이 몇 개인가 | 1개 이상 |

### T1 — 학습 맥락과 다른 새 맥락에서 같은 개념을 쓴다

**피자 문항의 구현** — 2차시는 모눈종이 정사각형과 쌓기나무로 k²·k³를 만들고, 평가 차시는 피자 주문·상자 검수 맥락에서 같은 관계를 쓴다. 차시 계획의 활동 문장에 '피자'는 한 번도 나오지 않는다.

**판정 절차**
1. `lesson1_act`~`lesson5_act`(평가 차시 제외)를 이어 붙여 문항 소재어(피자·주문·페퍼로니·치즈 등)를 센다. **0회여야 한다.** 1회라도 나오면 그 소재는 학습 맥락이지 새 맥락이 아니다.
2. 〔상 황〕·〔자료〕의 문장 가운데 **지우면 답이 달라지는 문장**을 센다. **2개 이상이어야 한다.** 0개면 맥락이 장식이다.

실제로 답을 바꾸는 맥락 문장 두 개:

```
※ 피자는 1판 단위로만 주문할 수 있으며, 반 판씩 나누어 팔지 않는다.
   → 2.048판을 3판으로 올리는 판단을 만든다. 지우면 소수 판 수가 답이 된다.
굽는 오븐의 높이 때문에 두께는 스몰과 같은 1.5 cm로 만들어야 합니다.
   → k³을 k²로 낮춘다. 지우면 세제곱근이 필요해져 중2 범위를 벗어난다.
```

### T2 — 공식을 주지 않고 학생이 관계를 도출한다

**피자 문항의 구현** — 조건 ①이 주는 것은 `(원의 넓이) = π × (반지름) × (반지름)`과 `(피자의 부피) = (윗면의 넓이) × (두께)` 둘뿐이다. '넓이의 비는 닮음비의 제곱', '부피의 비는 닮음비의 세제곱'은 학생 지면 어디에도 없다. 학생이 144π : 225π : 324π를 16 : 25 : 36으로 간단히 하고 4 : 5 : 6과 대조해 스스로 만든다.

**판정 절차** — 학생 지면(`item_intro` + `item_questions` + `item_cond`)만 이어 붙여 다음을 스캔한다. **각 0건이어야 한다.** 채점기준·예시답안에는 있어도 된다.

```
제곱한 비 / 세제곱한 비 / k² / k³ / 닮음비의 제곱 / 닮음비의 세제곱
```

조작적 정의는 예외다. "페퍼로니는 피자 윗면에만 올리므로 개수는 윗면의 넓이에 비례하게 정한다"는 **도출 대상이 아니라 채점 기준선**이므로 자료에 있어야 한다(→ M2).

**나쁜 예** — 리뷰가 제안한 발문 윤문:

> ㉯ … '서로 같은 두 수를 곱하여 **4가 되게** 하는 방법'으로 패밀리의 지름을 구하시오.

그 4는 `1808.64 ÷ 452.16 = 4`, 곧 채점 요건 값 자체다. 발문이 정답을 인쇄한다.

**좋은 예** — 채택한 문안:

> ㉯ 패밀리에 필요한 윗면 넓이가 미디엄 윗면 넓이의 **몇 배인지 구하고**, '서로 같은 두 수를 곱하여 **그 배수가** 되게 하는 방법'으로 패밀리의 지름을 구하시오.

도해도 같은 규칙이다. 운영 지침 9: "페퍼로니 배치, 부피 비교, 패밀리 설계를 보여 주는 도해는 정답을 드러내므로 학생용 지면에 넣지 않고 피드백 자료로만 쓴다."

### T3 — 오개념을 진단하는 장치가 있다

**피자 문항의 구현** — 〔자료 2〕 대화방에 ㉠·㉡ 두 오류 발언을 심고, 각 오류의 범위를 "…부터 …까지"로 문장 단위 고정한 뒤, 채점기준에서 ㉠ 반박과 ㉡ 반박을 각각 별도 요건으로 건다.

**판정 절차** — 넷을 모두 확인한다.
1. 자료에 심은 오류 주장이 **2개 이상**인가.
2. 각 오류에 범위 주석이 있는가. (`※ ㉠은 세아의 발언에서 '빅은'부터 '1.25판만큼이지.'까지를 … 가리킨다.`)
3. 각 오류가 **어느 채점 요소의 어느 하위요건**인지 1:1로 적혀 있는가.
4. 오류가 **수학적 오류**인가. 사실 오류·계산 실수는 안 된다.

**나쁜 예** — v3 초안의 하윤 발언:

> 그런데 라지 1판이면 26,000원이라 **제일 싸잖아.** 그냥 라지 시키면 안 돼?

가격표에는 미디엄 1판 16,000원이 인쇄돼 있다. 학생은 수학이 아니라 표를 다시 읽어서 반박하게 된다. 자료 내부 모순이지 오개념이 아니다.

**좋은 예** — 교체한 문안(선택지 제시 역할만 남기고 사실 오류 제거):

> 그런데 라지 1판이면 26,000원이라 **예산도 남잖아.** 그냥 라지 시키면 안 돼?

**좋은 예** — 심은 수학적 오류 두 개:

> 서연 : ㉠ 자이언트는 미디엄보다 지름이 36 ÷ 24 = 1.5배니까 먹을 수 있는 양도 1.5배야. 그러니까 자이언트 1판은 미디엄 1.5판만큼이지.
> 지호 : ㉡ 라지는 미디엄보다 지름이 1.25배니까 16 × 1.25 = 20개, 자이언트는 지름이 1.5배니까 16 × 1.5 = 24개야.

### T4 — 정답은 하나로 떨어지되 도달 경로가 여러 개다

**피자 문항의 구현** — 의사결정 문항의 정답은 ⓒ 하나다. 인정 경로 6종(① 1 cm³당 가격 ② 10,000원당 부피 ③ 부피 계수 비교 ④ 인분 환산 ⑤ 미디엄 판 수 환산 ⑥ 같은 금액 환산)을 python3로 각각 끝까지 계산해 전부 ⓒ임을 확인했다. 조건 ②(ㄷ)이 ①·②를 택1하게 하고, ③~⑥은 보충 근거로만 인정한다.

**판정 절차**
1. 서로 다른 경로 **2개 이상**을 python3로 끝까지 계산한다. 결론이 갈리면 목적함수가 모호한 것이다.
2. 두 경로의 **판단 방향이 반대**면(단가는 작을수록 유리, 10,000원당 부피는 클수록 유리) 채점기준에 두 값과 방향을 **모두** 인쇄한다. 한쪽만 적으면 다른 경로를 택한 답안이 0점이 된다.
3. 동치 단위율을 세 방안에 같은 정의로 적용한 답안도 인정한다고 유의점에 적는다. 인정하지 않으면 수학적 이해가 아니라 **지정 형식 준수**를 측정하게 된다. 동치 단위율은 두 계열로 갈리고 **판단 방향이 서로 반대**이므로 유의점에 계열별로 적는다.
   - 「가격 ÷ 양」 계열(작을수록 유리) — 1 cm³당 가격, 100 cm³당 가격, 1인분당 가격. 서로 상수배다.
   - 「양 ÷ 가격」 계열(클수록 유리) — 10,000원당 부피, 1,000원당 부피. 서로 상수배이고, 앞 계열의 역수다.

**나쁜 예** — v3 초안의 목적 진술("쓴 돈에 비해 가장 이득인 방안")은 ⓐ도 답이 될 여지를 남겼다.
**좋은 예** — 목적함수를 문장으로 고정: "예산 안에서 8명에게 필요한 양을 충족하는 방안 가운데, 쓴 돈에 비해 피자의 양이 가장 많은 방안." python3 검증 결과 충족 방안은 ⓐ·ⓒ뿐이고 그중 단위량당 값 최우는 ⓒ 단독.

### T5 — 역방향 추론(결과에서 조건을 되짚기)이 있다

**피자 문항의 구현** — 문항 1~3은 정방향(지름 → 넓이 → 부피)이고, 문항 4 ㉯만 역방향이다. 넓이가 4배 → `k × k = 4` → `k = 2` → 지름 `24 × 2 = 48 cm`. 네모피자판은 치즈 810 g → 넓이 3969 cm² → 스몰의 9배 → `k = 3` → 한 변 `21 × 3 = 63 cm`.

**판정 절차**
1. 채점 요건 가운데 「구한 값 → 그 값을 만든 조건」 방향이 **1개 이상** 있는가. 정방향만 있으면 미충족.
2. 역방향 요건에서 `kⁿ = m` 꼴이 나오면 **n ≤ 2이고 m이 완전제곱수**인가. n = 3이면 즉시 되돌린다(→ N1).
3. 역방향 실패가 **독립 진단 신호**로 쓰이게 배치했는가. 운영 지침 5-⑵: "문항 1부터 3까지가 만점인데 문항 4의 역방향 요건을 충족하지 못한 학생은 '역방향·조건 구분 실패형'으로 분류한다." 정방향만으로 만점이 나오는 구조면 이 신호가 안 생긴다.

## 오개념 층위 설계

닮음 단원에서 학생이 혼동하는 것은 **어떤 양에 몇 제곱을 쓰는가**다. 이를 「적용 자리 × 지수」 행렬로 배치한다.

### 행렬

한 문항 안에 **정답 지수가 서로 다른 자리를 둘 이상** 둔다. 피자 문항은 두 자리다.

| 답안이 쓴 지수 | **양(부피) 자리** — 정답 k³ | **페퍼로니 개수(윗면) 자리** — 정답 k² |
|---|---|---|
| k | ㉠ 자이언트 = 미디엄 **1.5판** ← 자료 2에 심음 | ㉡ 자이언트 **24개** ← 자료 2에 심음 |
| k² | 자이언트 = **2.25판** (유의점 D-4②) | **36개** = 정답 |
| k³ | **3.375판** = 정답 | **54개** (유의점 D-4③) |

6칸 가운데 정답이 2칸, 오답이 4칸이다. 자료에 심는 것은 k 행 2칸이고, 나머지 2칸은 채점 유의점에서 값과 함께 처리한다. 네모피자판도 같은 구조다(치즈: 정답 90·250 g / ㉡ 120·200 g / k³ 과잉 67.5·312.5 g).

### 규칙

**M1. 자리를 둘 이상 둔다.** 자리가 하나면 층위가 하나뿐이라 k/k²/k³ 혼동을 진단할 수 없다. 원판(넓이만)에서 부피판으로 개정한 이유가 이것이다.

**M2. 두 자리의 기준을 자료에서 조작적으로 정의한다.** 정의가 없으면 오답이 오답임을 확정할 근거가 없다.

```
※ 피자의 양은 부피로 비교하며, (피자의 부피) = (윗면의 넓이) × (두께)로 계산한다.
※ 페퍼로니는 피자 윗면에만 올리므로 개수는 윗면의 넓이에 비례하게 정한다.
※ 이 문항에서 '페퍼로니 1개당 윗면 넓이'는 '피자 윗면의 넓이 ÷ 페퍼로니 개수'를 뜻한다.
```

**M3. 자료에 심는 오개념은 가장 낮은 층(k)로 한다.** 두 자리 모두에 k 오류를 심으면 학생은 "이 자리에서 옳은 지수는 무엇인가"를 자리마다 따로 판단해야 한다. 그것이 이 문항의 핵심 사고다.

**M4. 심지 않은 층은 채점 유의점에 값과 함께 미리 적는다.** k³ 과잉일반화(54개)는 직전 차시에서 k³을 배운 직후이므로 반드시 나온다. 자료에 없다고 채점기준에서 빠뜨리면 채점자가 즉석에서 판단하게 된다.

**M5. 6칸의 값이 서로 다른지 확인한다.** 두 칸의 값이 같으면 채점자가 답안에서 경로를 복원할 수 없다. `16 × 1.5 = 24`, `16 × 2.25 = 36`, `16 × 3.375 = 54` — 셋이 다르다.

**M6. 오답끼리 곱해져 정답과 같아지는 조합을 찾아 막는다.** 실제로 나왔다: 잘못된 판 수 3 × 잘못된 개수 24 = **72**, 정답 2 × 36 = **72**.

> D-4①: … 잘못된 판 수 3에 개수를 곱하여 우연히 옳은 수가 나온 경우(예: 24 × 3 = 72)에도 (다)를 인정하지 않습니다.

**M7. 오개념은 대화문(또래)에 심고, 쪽지·안내문(권위자)에는 심지 않는다.** 쪽지는 과제만 준다. 사장님 진술은 자료의 사실로 읽히므로 오류를 심으면 자료 모순이 된다. 〔자료 3〕은 "라지와 자이언트에는 각각 몇 개씩 올려야 할까요?"처럼 묻기만 한다.

**M8. 귀속을 채점 요소 단위로 못 박고, 소문항 전체에 점수 상한을 두지 않는다.**

**나쁜 예** — 요소 전체 0점으로 읽혀 본표 1점 급간과 정면 충돌한 문안:

> D-4①. 양의 비교에 닮음비 k를 그대로 쓴 답안은 **문항 3 요소 2를 인정하지 않는다.**

같은 답안(두 단계 판단은 옳고 ㉠에만 동조)이 채점자에 따라 0점도 1점도 된다.

**좋은 예** — 하위요건 단위로 좁힌 문안:

> D-4①. 양의 비교에 닮음비 k를 그대로 쓴 답안은 문항 3 요소 2의 **㉠ 반박 하위요건을 인정하지 않는다.** 다만 필요한 양의 충족 확인과 단위량당 값 비교를 옳게 수행하였다면 요소 2의 1점 급간을 적용한다.

**M9. 오개념 교정용 피드백 활동도 수학적으로 옳은지 검산한다.**

**나쁜 예** — 폐기한 활동:

> 지름을 2배 한 원 안에 원래 원이 몇 개 들어가는지 직접 그려 넣어 볼까?

반지름 2r 원 안에는 반지름 r 원이 **최대 2개**만 들어간다(내부 원의 중심은 반지름 r 원판 안에 있어야 하고 중심 간 거리가 2r 이상이어야 하는데, 반지름 r 원판 안 두 점의 최대 거리가 정확히 2r이다). 학생이 그려 보면 2개가 나와 "지름 2배 → 넓이 2배"라는 **바로 그 오개념이 확증된다.**

**좋은 예** — 대체 활동(칸 수를 전수 계산해 확인):

> 모눈종이에 반지름이 4칸인 원과 8칸인 원을 각각 그리고, 두 원이 덮는 칸 수를 세어 보자.

**세는 규약을 반드시 함께 지정한다** — 원의 중심을 모눈선이 만나는 점에 놓고, **칸의 중심이 원 안에 있는 칸만** 센다. 아래 표는 이 규약으로 센 값이다. "칸 전체가 원 안에 들어가는 칸"으로 세면 같은 반지름에서 값이 전혀 달라져(4칸일 때 32칸) 표가 재현되지 않는다.

| 반지름 | 작은 원 | 큰 원(2배) | 비 | 쓸 수 있는가 |
|---|---|---|---|---|
| 1칸 | 4 | 12 | 3.000 | ✗ 오해 유발 |
| 2칸 | 12 | 52 | 4.333 | ✗ |
| 3칸 | 32 | 112 | 3.500 | ✗ |
| **4칸** | **52** | **208** | **4.000** | ✔ |
| 5칸 | 80 | 316 | 3.950 | ✗ 정확히 4배가 아님 |
| **6칸** | **112** | **448** | **4.000** | ✔ |

반지름 1~3칸은 비가 3.0~4.33으로 흔들리고, 5칸도 3.95라 정확히 4배가 아니다. **정확히 4배가 검산된 쌍(4칸·8칸 또는 6칸·12칸)만 지정한다.** '4칸 이상이면 된다'고 일반화하지 말 것 — `examples/examples-pizza.md`의 같은 규정과 일치해야 한다. 정사각형 판본("한 변이 2배인 정사각형 안에 원래 정사각형이 몇 개 들어가는지")은 빈틈없이 타일링되므로 정확히 4개이고, 그대로 써도 된다.

## 수치 설계 원칙

문항의 성패는 여기서 갈린다. 다섯 원칙을 순서대로 적용한다.

이 절의 k²/k³·정수 해·단가 비교 구조는 닮음(비례) 계열 단원의 어댑터다. 다른 영역(확률·통계·함수·기하 증명)에서는 '값이 학년 수준 표현으로 떨어진다', '오답 경로가 의미 있게 갈린다', '정답 유일성'의 일반 원칙만 가져가고 구체 구조는 단원에 맞게 새로 설계한다.

### N1 (ⓐ) 학년 범위 밖으로 새지 않게 한다

**규칙** — 학생이 구해야 하는 모든 값은 **유리수 사칙연산 + 완전제곱수의 제곱근 판별**만으로 나와야 한다. 역방향 산출에서 `kⁿ = m`이 나오면 **n ≤ 2, m은 완전제곱수**여야 한다.

**차수를 낮추는 방법** — 조건 하나를 고정한다. 고정 이유는 반드시 서사에 넣는다.

| 설계 | 고정하지 않으면 | 고정하면 |
|---|---|---|
| v2 패밀리: 16명분을 한 판에 | 부피 4배 → `k³ = 4` → `k = ∛4 = 1.5874…` **중2 밖** | 두께를 미디엄과 같은 2 cm로 고정 → `k² = 4` → `k = 2` → 지름 48 cm |
| 네모 파티팩: 치즈 810 g | 부피 9배 → `k³ = 9` → `k = ∛9 = 2.0801…` **중2 밖** | 치즈로 넓이를 직접 주어 `k² = 9` → `k = 3` → 한 변 63 cm |

**좋은 예** — 고정 조건을 서사로 정당화한 문장(인위성이 사라진다):

> 굽는 오븐의 높이 때문에 두께는 스몰과 같은 1.5 cm로 만들어야 합니다.
> 굽는 기계의 높이 때문에 두께는 미디엄과 같은 2 cm로 만듭니다.

**고정 조건을 잘못 인과화하지 말 것.** 이번 개발에서 나온 A급 결함이다.

**나쁜 예**:

> 두께를 고정하였으므로 부피가 넓이에 비례하고, 따라서 치즈가 알려 주는 윗면 넓이의 비만으로 **한 변을 구할 수 있다.**

한 변 63 cm를 구하는 데 두께는 전혀 필요 없다. `810 g → 3969 cm² → 3969 = 63 × 63 → 63 cm`. 두께 조건이 바꾸는 것은 한 변이 아니라 **부피**다. 이 기준대로면 "두께는 한 변 산출과 무관하다"고 정확히 쓴 학생이 오히려 만점을 못 받는다.

**좋은 예**:

> 치즈의 양은 윗면 넓이를 알려 주고, 윗면이 정사각형이므로 한 변은 **두께와 관계없이** 윗면 넓이에서 구할 수 있다. 윗면 넓이가 스몰의 9배이므로 한 변은 스몰의 3배인 63 cm이다. 이때 두께도 3배가 되면 부피는 3 × 3 × 3 = 27배이고, 두께를 1.5 cm로 고정하면 부피는 3 × 3 × 1 = 9배이다.

발문도 같이 고쳤다. "두께 고정이니까 한 변을 구할 수 있는 까닭"이 아니라 **두 경우의 부피를 각각 구하고 차이의 까닭**을 묻는다:

> ㉯ … 한 변이 스몰의 3배일 때 ⑴ 두께도 한 변과 같은 비율로 커지는 경우와 ⑵ 두께를 스몰과 같은 1.5 cm로 고정하는 경우의 부피가 각각 스몰의 몇 배가 되는지 각각 구하고, 두 결과가 달라지는 까닭을 서술하시오.

### N2 (ⓑ) 값이 정수·유한소수로 떨어지게 한다

**규칙** — 학생이 구하는 **기초 산출값**(길이·넓이·부피·개수·양)은 전부 유한소수여야 한다. 판정은 기약분수의 분모를 2와 5로 계속 나눠 1이 되는지로 한다. 예외는 **단위량당 값 하나**뿐이고, 그것만 조건에서 반올림 자리를 지정하고 계산기를 허용한다. 곧 단위량당 값 등 나눗셈 결과 하나는 순환소수여도 되며, 그 값의 표기는 반올림 표기 규칙(조건)에 위임한다.

**사례 — 원을 정사각형으로 바꿔 π를 없앴다.**

| | 원판(미디엄/라지/자이언트) | 정사각형판(스몰/미들/빅) |
|---|---|---|
| 윗면 넓이 | 144π · 225π · 324π (무리수) | **441 · 784 · 1225** (정수) |
| 3.14로 볼 때 | 452.16 · 706.5 · 1017.36 | 해당 없음 |
| 부피 | 288π · 562.5π · 972π | **661.5 · 1568 · 3062.5** |
| 페퍼로니/치즈 | 16 · 25 · 36개 | 90 · 160 · 250 g |

π 하나 때문에 원판에는 조항이 다섯 개 붙었다 — 조건 ①의 aπ/3.14 병행 허용, 부분 점수 원칙 3(원주율 표기 단일 규칙), 원칙 5(반올림 자리 관용), 유의점 A-1(π 표기 인정), 유의점 D-2(π 표기는 어느 쪽도 미충족 아님). 정사각형으로 바꾸자 다섯 조항이 전부 소멸했다.

**나쁜 예** — 목적 설명에 실제로 적혀 있던 문장:

> **모든 산출값이** 정수나 유한소수로 떨어지므로 학생의 인지 부담이 계산이 아니라 논증에 놓인다.

사실이 아니다. 필수 단위량당 값이 전부 순환소수다.

```
32000 ÷ 3136 = 10.204081…
25000 ÷ 3062.5 =  8.163265…
34000 ÷ 3724  =  9.129967…
3724  ÷ 3.4   = 1095.294117…
```

**좋은 예** — 교체한 문장:

> 윗면 넓이·부피·치즈 양 등 **핵심 기초 산출값은** 정수나 유한소수로 떨어지고, **단위량당 값은** 계산기를 이용하여 소수 첫째 자리까지 반올림하도록 하므로, 학생의 인지 부담이 계산 자체보다 비의 구별과 논증에 놓이도록 하였다.

### N3 (ⓒ) 변별이 생기게 한다

**규칙** — 정답 경로의 최종값과 각 오답 경로의 최종값이 **서로 달라야** 한다. 파라미터(인원수·기준량)는 후보 범위를 전부 훑어서 갈리는 값만 채택한다.

**사례 — 인원수 12명 → 16명.** v3 넓이판에서 자이언트 1판은 9명분이고 ㉠ 경로(양에 k를 씀)는 6명분이다. 필요 판 수를 인원별로 전수 계산했다.

| 인원 | 정답 경로 | ㉠ 경로 | |
|---|---|---|---|
| 8명 | 1판 | 2판 | 갈림 |
| 10명 | 2판 | 2판 | **변별 실패** |
| **12명** | **2판** | **2판** | **변별 실패** |
| 14명 | 2판 | 3판 | 갈림 |
| **16명** | **2판** | **3판** | **갈림 → 채택** |
| 20명 | 3판 | 4판 | 갈림 |

12명이면 오개념을 그대로 가진 학생도 정답과 같은 2판을 적는다. 16명으로 바꿔야 판 수가 2판과 3판으로 갈린다. 이 한 수치가 문항 4의 진단력 전부를 결정한다.

네모피자판도 같은 검사를 했다. 빅 1판이 7.8125인분, ㉠ 경로가 5인분이므로 **8명이면 둘 다 2판(변별 실패)**, 16명이면 3판과 4판으로 갈린다.

### N4 (ⓓ) 판단이 두 단계로 강제되게 한다

**규칙** — **단가가 가장 유리한 선택지와 정답 선택지를 다르게** 한다. `min(단가) == 정답`이면 학생은 단가 비교 한 단계만으로 답에 닿고, "필요량 충족 → 단위량당 비교"라는 두 단계 사고가 측정되지 않는다.

**사례** — 두 판 모두 ⓑ에 트레이드오프를 심었다.

| 판 | 방안 | 부피 | 단가 | 필요량 | 판정 |
|---|---|---|---|---|---|
| v2 부피판 | ⓐ 미디엄 2판 30,000원 | 1808.64 | 16.6원 | 1808.64 | 정확히 충족 |
| | **ⓑ 라지 1판 26,000원** | **1766.25** | **14.7원(ⓐ보다 유리)** | | **42.39 cm³ 부족** |
| | ⓒ 자이언트 1판 32,000원 | 3052.08 | **10.5원** | | 충족 → **정답** |
| 네모피자판 | ⓐ 미들 2판 32,000원 | 3136 | 10.2원 | 3136 | 정확히 충족 |
| | **ⓑ 빅 1판 25,000원** | **3062.5** | **8.2원(최저)** | | **73.5 cm³ 부족** |
| | ⓒ 빅+스몰 34,000원 | 3724 | 9.1원 | | 충족 → **정답** |

**부족량 규모 규칙** — 부족량은 **1인분 미만**이어야 한다. 두 판 모두 `0.1875인분`(1인분의 18.75%)이다. 크게 모자라면 학생이 눈으로 걸러서 두 단계 판단이 되지 않고, 정확히 맞으면 트레이드오프가 사라진다.

**조건에 명시한다.** 채점기준에만 두면 발문에 없는 요구를 채점하는 것이 된다.

> 조건 ⑤ 둘째 문단 : ②의 (ㄷ)에서 고른 값을 근거로 어느 방안이 가장 이득인지 밝힐 것. 이때 다른 방안보다 단위량당 값이 유리한데도 필요한 양에 미치지 못하여 고를 수 없는 방안이 있으면 그 까닭을 함께 밝힐 것.

**조합 방안을 넣었으면 단가 정의를 조건에 적는다.** 개별 단가의 단순평균을 막는다.

> ⓒ는 두 피자의 가격을 합한 값과 두 피자의 부피를 합한 값을 이용하여 방안 전체의 단위량당 값을 구할 것.

### N5 (ⓔ) 오답 경로의 값도 미리 계산해 둔다

**규칙** — 각 오답 경로의 최종값을 전부 계산해 표로 남긴다. 채점 유의점 D에는 이 표의 값이 그대로 들어간다. **채점기준·유의점에 등장하는 수치 가운데 이 표에 없는 것이 있으면 그것은 검산되지 않은 수치다.**

v2 부피판의 사전 계산표:

| 오답 경로 | 최종값 | 귀속 |
|---|---|---|
| 양에 k (㉠ 동조) | 자이언트 1.5판, 16명 → **3판** | D-4① |
| 양에 k² | 자이언트 2.25판, 필요량 1808.64 cm², 세 방안 904.32 / 706.5 / 1017.36 cm² | D-4② |
| 개수에 k³ (과잉일반화) | **54개** | D-4③ |
| 넓이 4배를 지름 4배로 | **96 cm** | D-5④ |
| 지름을 반지름으로 | 넓이·부피 전량 오류 | D-5① |

**오답 경로 안에서 동률이 생기는지도 검사한다.** 네모피자판에서 실제로 나왔다. 넓이의 비를 부피의 비로 잘못 쓴 답안의 값은 스몰 882, 미들 1568, 빅 2450이고, 세 방안은 ⓐ 3136 / ⓑ 2450 / ⓒ 3332가 된다. 이때 단가는:

```
32000 ÷ 3136 = 10.204081…
25000 ÷ 2450 = 10.204081…      ← 셋이 완전 동률
34000 ÷ 3332 = 10.204081…
```

원인은 가격 수열이다. `9000 : 16000 : 25000 = 9 : 16 : 25 = k²`, 곧 가격을 넓이에 정확히 비례시켜 두었다. 넓이를 부피로 오인한 답안 안에서는 세 방안이 구별되지 않고, "자신이 구한 값에 대해 절차가 옳으면 인정"이라는 규정만으로는 점수를 정할 수 없다.

→ **검사 항목**: 각 오답 경로에 대해서도 선택지별 단가를 계산해 전부 같지 않은지 확인한다. 같으면 가격 수열이나 부피 수열을 바꾼다. 바꾸지 않기로 했다면 유의점에 처리를 못 박는다:

> 앞에서 구한 잘못된 값을 일관되게 사용한 결과 방안의 대소 관계가 달라진 경우에도, 필요한 양 충족 확인 → 동일한 단위량당 값 계산 → 자신의 값에 맞는 결론의 절차가 일관되면 후속 판단 절차는 인정한다. 다만 부피비를 잘못 선택한 개념 오류는 문항 3 요소 1에서 감점한다.

## 수치 검산 게이트

초안 에이전트는 초안과 함께 아래 게이트를 python3로 돌리고 **출력 전문을 반환**한다. 실패가 하나라도 있으면 초안이 아니라 수치를 고친다. 자기 보고("전 항목 통과")는 믿지 않는다 — 실제 결함은 전부 게이트와 적대적 검증에서 나왔다.

### 전수 재계산 항목

| # | 항목 | 통과 기준 |
|---|---|---|
| G1 | 자료에 인쇄된 원자료(치수·가격·예산·인원·기준량) | 스크립트 상수와 문서가 1:1 일치 |
| G2 | 모든 길이·넓이·부피·개수·양 | 재계산값 = 문서값 |
| G3 | 모든 비와 가장 간단한 자연수의 비 | `Fraction`으로 약분해 일치 |
| G4 | 1인분·필요량·판 수 | 올림 방향까지 일치(`ceil`) |
| G5 | 모든 단위량당 값 | 반올림 **전** 원값과 **후** 값을 둘 다 |
| G6 | 선택지별 총액과 예산 충족 여부 | 전 선택지 예산 이하 |
| G7 | 역방향 산출값(k, 한 변, 지름) | `kⁿ = m`에서 n ≤ 2, m 완전제곱 |
| G8 | 오답 경로 각각의 최종값(N5 표) | 6칸 값 전부 상이 |
| G9 | 오답 경로 안의 선택지 동률 | 전부 같지 않음 |
| G10 | 정답/오답 판 수 변별 | 갈림 |
| G11 | 단가 최유리 ≠ 정답 | 두 단계 강제 |
| G12 | 기초 산출값 유한소수 | 분모가 2^a·5^b |
| G13 | 문서(채점기준·예시답안·유의점·성취수준)에 인쇄된 모든 수치 | 정규식으로 뽑아 G1~G8 집합과 대조, 미검산 수치 0 |
| G14 | 배점 합계·급간 수 | 문항 배점 합 = 총점. 수행평가는 요소별 급간이 배점부터 1까지, 지필평가는 배점부터 0까지 1씩 하강(데이터 행 수 = 총점 + 요소 수). 학교 규정 오버라이드가 있으면 실제 적용 최저 급간까지 하강 |

### 학년 범위 자동 검사

세 겹으로 한다.

**⑴ 값 검사** — 유한소수 판정(G12), 완전제곱 판정(G7), 차수 판정(`kⁿ`의 n ≤ 2).

**⑵ 토큰 검사** — 학생 지면 텍스트를 스캔한다. 중2 도형의 닮음 기준 목록:

| 구분 | 토큰 |
|---|---|
| 금지(중3 이후) | `√` `∛` `제곱근` `세제곱근` `무리수` `유리화` `피타고라스` `삼각비` `sin` `cos` `tan` `원주각` `이차방정식` `인수분해` `이차함수` `로그` |
| 허용(기학습) | `π`/`원주율`(초6 [6수03-08]) · `비`/`비율`(초6) · 유리수 사칙연산(중1) · 겉넓이·부피(중1) |

목록도, 표에 적힌 성취기준 코드도 학년·단원마다 NCIC 공시 자료에서 다시 뽑는다. 위 `[6수03-08]`은 피자 문항 개발 기록에서 옮긴 값이므로 **기억이나 이 문서를 근거로 인용하지 말고 `references/standards.md` §1의 절차로 원문을 확인한 뒤 쓴다.** 채점기준·유의점에는 금지 토큰이 있어도 된다(예: "중3 이후에 배우는 제곱근·세제곱근 기호를 써서 지름을 구한 답안은 감점하지 않되 가점도 하지 않는다").

**⑶ 학년 귀속 검사** — 문서가 개념을 어느 학년 것으로 적었는지 대조한다. 이번 개발에서 실제로 나온 오류: "**중1에서** 배운 원의 넓이 공식" → 원의 넓이는 [6수03-08]이므로 "**초등학교에서** 배운"으로 정정.

### 검산 스크립트 뼈대

아래를 그대로 복사해 쓴다. 실제로 이 뼈대가 N2의 순환소수 결함을 잡아냈다.

- **손대지 않는 부분** — 맨 위 함수 정의부(`fail`·`eq`·`is_finite`·`rq`·`finite`·`finite_note`·`sqrt_exact`·`scan_student_page`·`cross_check`)와 맨 아래 실패 목록 출력.
- **문항마다 다시 쓰는 부분** — `# ── 입력 ──`부터 `# ── G11 ──`까지 전부. 아래 값은 네모피자판 전용이다. 다른 문항에서 상수만 바꾸고 파생식(`plans`·`grid`·`wrong_vol`)을 그대로 두면 그 문항과 무관한 값을 검산하게 된다.
- **뼈대가 덮지 않는 게이트** — G13(문서 대조)은 주석 처리돼 있고 G14(배점 합계·급간 수열)는 아예 없다. 둘은 직접 추가해서 돌린다. G14는 `references/rubric-rules.md` §7의 검사와 같다.

```python
# -*- coding: utf-8 -*-
"""수치 검산 게이트 — 초안과 함께 반드시 실행하고 출력 전문을 반환한다."""
from fractions import Fraction as F
from decimal import Decimal, ROUND_HALF_UP
from math import ceil, isqrt
import re

FAIL = []
def fail(tag, msg): FAIL.append(f"[{tag}] {msg}")

def eq(name, got, printed):                       # G1~G6  값 대조
    if F(got) != F(printed): fail("값", f"{name}: 재계산 {got} ≠ 문서 {printed}")
    print(f"  {name} = {got}")

def is_finite(x):
    d = F(x).denominator
    while d % 2 == 0: d //= 2
    while d % 5 == 0: d //= 5
    return d == 1

def rq(x, q="0.1"):                               # 반올림 — round()는 짝수 쪽 반올림이라
    # 학교 수학의 사사오입과 다를 수 있으므로
    # Decimal(str(x)).quantize(Decimal(q), rounding=ROUND_HALF_UP)을 쓴다
    return (Decimal(x.numerator) / Decimal(x.denominator) if isinstance(x, F) else Decimal(str(x))).quantize(Decimal(q), rounding=ROUND_HALF_UP)

def finite(name, x):                              # G12  기초 산출값은 실패로 잡는다
    if not is_finite(x): fail("유한소수", f"{name} = {F(x)} → {float(x):.6f}… 순환소수")

def finite_note(name, x):                         # 단위량당 값은 예외 — 보고만 한다
    if not is_finite(x):
        print(f"  [주의] {name} = {F(x)} → {float(x):.6f}… 순환소수. "
              f"문서 설명이 '모든 산출값'이 아니라 '핵심 기초 산출값'으로 한정돼 있는지 확인할 것.")

def sqrt_exact(name, m):                          # G7  역방향 차수·완전제곱
    m = F(m)
    if m.denominator != 1:
        fail("역방향", f"{name}: k² = {m} 가 정수가 아님"); return None
    r = isqrt(m.numerator)
    if r * r != m.numerator:
        fail("역방향", f"{name}: k² = {m} 는 완전제곱수가 아님 → 무리수"); return None
    return r

BANNED = ["√","∛","제곱근","세제곱근","무리수","유리화","피타고라스",
          "삼각비","sin","cos","tan","원주각","이차방정식","인수분해","이차함수","로그"]
LEAK   = ["제곱한 비","세제곱한 비","k²","k³","닮음비의 제곱","닮음비의 세제곱"]

def scan_student_page(text):                      # ⑵ 토큰 + T2 정답 노출
    for t in BANNED:
        if t in text: fail("학년범위", f"학생 지면에 미학습 개념어 '{t}'")
    for t in LEAK:
        if t in text: fail("정답노출", f"학생 지면에 결론 관계식 '{t}'")

def cross_check(doc_text, computed, extra_ok=()):  # G13  미검산 수치 색출
    # 배점·문항 번호는 값이 아니라 '위치'로 제외한다 — range(0, 21) 같은 값 화이트리스트를
    # 두면 16개·4배·9배·20 g 같은 실제 정답 수치까지 통째로 덮여 G13이 무력해진다.
    doc_text = re.sub(r"(?:〔?\s*문항|채점\s*요소|평가\s*요소)\s*\d+|\(?\d+\s*점\)?", " ", doc_text)
    # 자릿점(32,000)을 한 수로 잡는다. r"\d+(?:\.\d+)?" 로 두면 32와 000 으로 쪼개져
    # 문서의 모든 가격·예산이 재계산 집합에 걸려 조용히 통과한다.
    printed = {F(s.replace(",", "")) for s in re.findall(r"\d[\d,]*(?:\.\d+)?", doc_text)}
    known   = {F(x) for x in computed} | {F(x) for x in extra_ok}
    for v in sorted(printed - known):
        fail("미검산", f"문서에 있으나 재계산 집합에 없는 수치: {v}")

# ── 입력: 자료에 인쇄되는 원자료만 여기 둔다 ─────────────────────────
SIDE   = {"스몰": 21, "미들": 28, "빅": 35}
THICK  = {"스몰": F(3,2), "미들": 2, "빅": F(5,2)}
PRICE  = {"스몰": 9000, "미들": 16000, "빅": 25000}
BUDGET, HEADS, HEADS2, CHEESE_MID = 35000, 8, 16, 160
PARTY_CHEESE = 810

# ── G2·G3 파생값 전수 재계산 ────────────────────────────────────────
print("── 기초 산출값 ──")
area = {k: SIDE[k] ** 2 for k in SIDE}
vol  = {k: area[k] * THICK[k] for k in SIDE}
eq("스몰 윗면", area["스몰"], 441); eq("미들 윗면", area["미들"], 784); eq("빅 윗면", area["빅"], 1225)
eq("스몰 부피", vol["스몰"], F(1323,2)); eq("미들 부피", vol["미들"], 1568); eq("빅 부피", vol["빅"], F(6125,2))
per_g = F(area["미들"], CHEESE_MID); eq("치즈 1 g당 넓이", per_g, F(49,10))
eq("스몰 치즈", area["스몰"] / per_g, 90); eq("빅 치즈", area["빅"] / per_g, 250)

# ── G4 1인분·필요량·판 수 ──────────────────────────────────────────
serving = F(vol["미들"], 4); eq("1인분", serving, 392)
need    = serving * HEADS;   eq("8명 필요량", need, 3136)
need2   = serving * HEADS2;  eq("16명 필요량", need2, 6272)
eq("빅 최소 판 수(16명)", ceil(need2 / vol["빅"]), 3)

# ── G5·G6 선택지 ───────────────────────────────────────────────────
plans = {"ⓐ": (2*vol["미들"], 2*PRICE["미들"]),
         "ⓑ": (vol["빅"],      PRICE["빅"]),
         "ⓒ": (vol["빅"]+vol["스몰"], PRICE["빅"]+PRICE["스몰"])}
unit   = {k: F(p) / v for k, (v, p) in plans.items()}
enough = {k: v >= need for k, (v, p) in plans.items()}
for k, (v, p) in plans.items():
    if p > BUDGET: fail("예산", f"{k} 총액 {p} > 예산 {BUDGET}")
    print(f"  {k}: 부피 {v} 총액 {p} 단가 {float(unit[k]):.6f} → {rq(unit[k])}원 "
          f"{'충족' if enough[k] else '미달'}")

# ── G12 유한소수 ───────────────────────────────────────────────────
for k in area: finite(f"{k} 윗면", area[k]); finite(f"{k} 부피", vol[k])
for k in SIDE: finite(f"{k} 치즈", F(area[k]) / per_g)
finite("1인분", serving); finite("8명 필요량", need); finite("16명 필요량", need2)
for k in unit: finite_note(f"{k} 단가", unit[k])     # 예외 — 실패가 아니라 보고

# ── G7 역방향 ──────────────────────────────────────────────────────
party_area = PARTY_CHEESE * per_g; eq("파티팩 윗면", party_area, 3969)
ratio = F(party_area, area["스몰"]); eq("스몰 대비 배수", ratio, 9)
k = sqrt_exact("파티팩 한 변", ratio)
if k: eq("파티팩 한 변", SIDE["스몰"] * k, 63)

# ── G8·G10 오답 경로 사전 계산과 변별 ───────────────────────────────
print("── 오답 경로 ──")
kk = F(SIDE["빅"], SIDE["미들"])                       # 1.25
grid = {"k":  {"양": kk * 4,      "치즈": CHEESE_MID * kk},
        "k²": {"양": kk**2 * 4,   "치즈": CHEESE_MID * kk**2},
        "k³": {"양": kk**3 * 4,   "치즈": CHEESE_MID * kk**3}}
for exp, row in grid.items():
    print(f"  {exp}: 빅 = {row['양']}인분 / 치즈 {row['치즈']} g")
for col in ("양", "치즈"):                          # M5·G8 — 단위가 같은 열 안에서만 비교한다
    vals = [grid[e][col] for e in grid]             # 인분과 g을 한 집합에 섞으면 판정이 무의미하다
    if len(set(vals)) != len(vals): fail("층위", f"'{col}' 자리의 k/k²/k³ 값 중 겹치는 칸이 있음")

right_plates = ceil(need2 / vol["빅"])
wrong_plates = ceil(F(HEADS2) / grid["k"]["양"])
print(f"  16명 판 수: 정답 {right_plates} / k경로 {wrong_plates}")
if right_plates == wrong_plates:
    fail("변별", f"인원 {HEADS2}에서 정답·오답 판 수가 {right_plates}판으로 같음")

# ── G9 오답 경로 안의 선택지 동률 ───────────────────────────────────
wrong_vol = {s: F(vol["미들"]) * F(area[s], area["미들"]) for s in SIDE}   # 넓이비를 부피비로 오인
wp = {"ⓐ": (2*wrong_vol["미들"], 2*PRICE["미들"]),
      "ⓑ": (wrong_vol["빅"],      PRICE["빅"]),
      "ⓒ": (wrong_vol["빅"]+wrong_vol["스몰"], PRICE["빅"]+PRICE["스몰"])}
wu = {k: F(p) / v for k, (v, p) in wp.items()}
print("  k² 오인 경로 단가:", {k: str(rq(v, "0.0001")) for k, v in wu.items()})
if len(set(wu.values())) == 1:
    fail("동률", "오답 경로 안에서 세 방안의 단가가 완전 동률 → 채점 불능")

# ── G11 두 단계 판단 강제 ──────────────────────────────────────────
cheapest = min(unit, key=unit.get)
answer   = min([k for k in plans if enough[k]], key=unit.get)
print(f"  단가 최유리 {cheapest} / 충족 {[k for k in enough if enough[k]]} / 정답 {answer}")
if cheapest == answer: fail("두단계", "단가 최유리 방안이 곧 정답 → 판단이 한 단계로 무너짐")
short = need - plans[cheapest][0]
if not (0 < short < serving):
    fail("부족량", f"트레이드오프 방안의 부족량 {short} 이 0 초과 1인분 미만이 아님")

# computed 에는 원자료 상수까지 전부 넣는다. 파생값만 넣으면 가격·예산·치즈량이
# 통째로 '미검산'으로 뜨고, 반올림한 단가는 원값과 반올림값을 둘 다 넣어야 한다(G5).
```

- **[주의]** — N2의 허용 예외(단위량당 값)다. 수치는 그대로 두되, **문서 설명이 "모든 산출값"이 아니라 "핵심 기초 산출값"이라고 적혀 있는지** 확인한다. 예외를 스크립트에서 조용히 빼기만 하고 문서를 안 고치면 N2의 나쁜 예를 그대로 재생산한다.

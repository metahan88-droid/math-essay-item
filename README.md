# 중등 수학 서·논술형 문항 개발

성취기준에서 출발해 **문항 초안 → 채점 요소 → 급간별 수행 수준 → HWPX 조판**까지 완성하는 Claude Code 스킬과, 그 스킬을 만들며 남긴 개발 기록입니다.

중2 「도형의 닮음」 수행평가 문항(피자 GRASPS, 20점 4문항)을 실제로 개발하면서 겪은 실패를 규칙으로 굳혔고, 그 규칙을 다시 적대적 검증으로 6라운드에 걸쳐 다듬었습니다.

## 무엇이 들어 있나

| 폴더 | 내용 |
|---|---|
| `skills/math-essay-item-backup/` | **스킬 본체.** `~/.claude/skills/math-essay-item/`에 복사하면 그대로 쓸 수 있습니다 |
| `wiki/` | 개발 기록. 문항 설계 판단, 조판 사고, Codex 적대적 감사 전문 6건 |
| `tools/` | HWPX 빌드·검증 도구와 작업 중 슬롯 JSON |
| `hwpx/`, `outputs/` | 조판 산출물 |
| `figs/` | 문항 자료 도해(직접 작도한 SVG·PNG) |
| `refs/` | 참고 자료 |

## 스킬이 하는 일

0. 성취기준·평가 요소·총점·**평가 유형**(수행평가/지필평가)을 입력받는다
1. 서로 다른 소재 각도로 문항 초안 3개를 병렬 생성하고 수치를 python3로 전수 검산한다
2. 사용자가 고르고 다듬는다
3. 채점 요소와 급간별 수행 수준을 쓴다
4. 검증 세 겹 — 급간 게이트 · 어긋남 리뷰어 · **Codex 적대적 검증(필수)**
5. 자료 그림을 만든다(글자가 문항 내용이면 직접 작도, 분위기 삽화만 AI)
6. HWPX로 조판하고 검증한다

## 이 스킬이 붙잡고 있는 것

**급간을 가르는 축은 요소마다 하나 — 옳게 수행한 원자 수행의 개수.**
종전 뼈대는 한 요소 안에 정오·완성도·착수 세 축이 섞여 있었고, 2ⁿ 전수 열거로 재보니 백지 답안이 두 급간에 동시에 걸리고(겹침) 어떤 답안은 어느 급간에도 걸리지 않았습니다(공백). 개수 축으로 통일해 모든 단수에서 겹침 0·공백 0을 확인했습니다.

**형식이 맞아도 타당도는 별개입니다.**
개수 축은 배타성을 풀었지만, 원자가 서로의 입력인 구조(넓이의 비 → 부피의 비 → 관계 설명)에서는 한 번의 산술 오류가 세 원자를 무너뜨려 4점 중 2점이 됩니다. 2ⁿ 열거로는 절대 드러나지 않는 결함이라, 의존 그래프를 필수로 하고 같은 문항 안의 연쇄까지 구제하는 규정을 두었습니다.

**평가 유형에 따라 0점 처리가 갈립니다.**

| 항목 | 수행평가(기본) | 지필평가(정기고사) |
|---|---|---|
| 최저 급간 | 1점 | 0점 |
| 0점 진술 | 없음 | `무응답 또는 그 외의 오답.` 고정 |
| 요소 최소 배점 | 2점 | 1점 |
| 데이터 행 수 | 총점 | 총점 + 요소 수 |
| 성취수준 | 도달 가능 구간 재분할 | 0~총점 자연 분할 |

학교 학업성적관리규정이 다르면 규정이 우선하며, 검사 코드의 `SCHOOL_OVERRIDE`로 실제 값을 넣어 검사합니다.

## 검증 체계

- **기계 검사** — 채점기준표 16종 검사(배점 항등식, 급간 하강, 문체, 축 혼용, 원자 정의 정합), 성취수준 구간의 도달 가능성, HWPX 구조·레이아웃·내용 보존·BinData 정합
- **2ᵐ 전수 열거** — 요소마다 원자 충족 벡터를 전수 대입해 겹침·공백을 판정. 표준 뼈대를 썼다는 것이 면제 사유가 되지 않습니다
- **적대적 검증** — 같은 모델은 같은 맹점을 공유하므로 Codex로 별도 감사를 겁니다. `wiki/스킬/Codex-스킬감사-*.md`가 그 기록이고, A급 지적이 라운드마다 나왔습니다

## 쓰는 법

```bash
cp -R skills/math-essay-item-backup ~/.claude/skills/math-essay-item
```

Claude Code에서 "서논술형 문항 만들어줘" 같은 말로 부르면 됩니다. 스킬이 성취기준·평가 요소·평가 유형을 물어봅니다.

HWPX 조판은 한글 서식 파일(`tools/tpl2/`)에 의존합니다. 그림을 PNG로 만들려면 `rsvg-convert`(`brew install librsvg`)가 필요합니다.

## 덜어낸 것

제출용 최종 HWPX 4개와 그 슬롯 JSON 4개는 소속·성명이 들어 있어 이 저장소에서 뺐습니다. 같은 문항의 이전 판본과 스킬에 동봉된 익명 예시(`skills/math-essay-item-backup/examples/valid-similarity-20pt.json`)로 형식을 확인할 수 있습니다.

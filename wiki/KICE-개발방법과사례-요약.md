# [고등학교 일반 선택 과목] 서·논술형 평가 도구 개발의 방법과 사례 : 수학 (KICE ORM 2025-91-2)

한국교육과정평가원 연구자료 **ORM 2025-91-2**(2025.12.31 발행, 총 216쪽). 교육부 수업혁신융합교육과 + KICE 수업·평가혁신연구본부 국가평가관리센터 제작. 집필진 박민규·윤혜미·이상조·이승철·최승호·최인선, 검토진에 **송윤호(서울대사대부여중)** 포함. 구성은 **Ⅰ. 이론 및 정책적 이해(p.5–15) / Ⅱ. 평가 도구 개발 및 적용(p.16–23) / Ⅲ. 개발 사례 18건(p.24–211) / 도움 자료(p.212) / 참고문헌(p.213–214)**. 서·논술형 개발을 **4단계 모형**(평가 계획 → 평가 문항 개발 → 채점기준 개발 → 채점 및 피드백)으로 제시하며, 서술형/논술형 특성 대조표(p.10)와 평가요소·채점요소의 시간적 구별(p.17·p.20)이 이 자료의 가장 큰 이론적 기여다. 인쇄 쪽번호 = PDF 페이지 번호로 일치.

## Key Points

### 서지·계보
- Ⅱ장은 **2024년 자료집**(박종임 외, 2024c, ORM 2024-150-3)을 수정·보완한 것[p.16 각주 5]. Ⅱ장 예시는 모두 고등학교 공통 과목(공통수학1, 행렬) 대상 2024년 사례[p.16 각주 *].
- 2024년 자료집은 지필평가 같은 **일회성 평가 기준**으로 개발했으나, **2025년 자료집은 지필평가와 수행평가 양 측면에서 서·논술형 문항을 모두 개발**[p.17 각주 *].
- Ⅲ장 도입 안내문[p.24]: 수행평가 유형 평가 도구에는 '평가 도구 정보표' 다음에 **'교수·학습 활동 및 평가 계획'**을 제시. 학교 현장에서는 전체 적용도, 일부 문항 선별 적용도 가능.

### Ⅰ장 — 이론·정책 (p.5–15)
- 필요성: 6대 핵심역량, '무엇을 아는가'→'무엇을 할 수 있는가'. 선택형 중심 평가의 한계. "서·논술형 평가에서 요구하는 공통적인 능력은 **'사고'**"(p.6).
- 문항 유형 범주표(p.7, Mehrens & Lehmann 1991:54 수정), 채점 객관성에 따른 분류(p.8), **에세이 유형 구분 — 제한 응답형/확장 응답형**(p.9, Gronlund 1988:26 등).
- ★ **서술형/논술형 일반적 특성 대조표**(p.10, 박종임 외 2024:6 · 박혜영 외 2019a:33 수정) — 정의·응답 분량·평가하려는 행동 특성·정답 허용 범위 4축.
- 지필평가 문항 유형 분류(p.11) / 수행평가 과제 유형(p.12) — **출처 2024b가 중학교판 『학생평가 톺아보기』 ORM 2024-158-2**이므로 중2 사전과제에 그대로 원용 가능.
- 교육과정 총론 변천(p.13) 및 정책 계보(p.14–15): 수행평가 도입(1998~) → 학사관리 선진화(2011~, 20~40%) → 과정중심평가(2015~) → 서·논술형 강화(2023~). 2025 학생부 기재요령: "**지필평가는 서·논술형 문항만으로도 평가할 수 있음.**"
→ [[서술형과-논술형의-구분]]

### Ⅱ장 — 4단계 개발 모형 (p.16–23)

| 단계 | 절 | 하위 산출물 | 쪽 |
|---|---|---|---|
| 1 | 평가 계획 | ◇성취기준 및 성취수준 분석하기 / ◇평가 요소 선정하기 / [참고] 용어 정리하기 | p.16–17 |
| 2 | 평가 문항 개발 | ◇평가 문항 개발하기(발문·자료·조건) / ◇예시 답안 작성하기 | p.18–19 |
| 3 | 채점기준 개발 | ◇채점기준 개발하기(채점 요소·점수·수행 특성) / ◇성취수준별 학생 수행 특성 예측하기 | p.20–21 |
| 4 | 채점 및 피드백 | ◇채점 및 학생 개별 피드백하기 | p.22–23 |

- **성취수준 위계 조절 어휘**(p.16, [10공수1-04-02]): A "다양한" → B (무표) → C "간단한" → D (하위 행동만) → E "안내된 절차에 따라".
- **평가 요소 진술 형식**(p.17): "**반드시 '~하기'의 형태로 진술할 필요는 없으며**, 평가 내용을 구체적으로 포함하는 것에 초점".
- ★ **평가 요소 vs 채점 요소의 시간적 구별**(p.17): "평가 요소는 성취기준 분석 단계에서 도출되지만, **채점 요소는 문항을 개발한 이후에 구체적으로 기술이 가능**합니다." 채점 요소는 평가 요소와 동일할 수도, **추가·통합·세분화**될 수도 있음(p.20).
- **문항 3요소 구조**(p.18): 자료(간접 발문 포함) / (직접) 발문 / 조건. 조건은 ⑴ **해결 방법의 제한** ⑵ **표현 형식의 제한** 두 종류. 총점 `[N점]`은 총괄 발문 옆, 소문항 `(N점)`은 각 소문항 끝.
- **발문·조건 원칙**(p.19): 발문에 응답의 내용과 범위가 명확히 제시되어야 하며, 부족하면 조건 활용. "'조건'이 **과다하거나 모호**하게 제시된 경우에는 답안 작성 및 채점에 혼란을 가져올 수 있으므로 유의."
- **예시 답안을 문항 개발 단계에 함께 써야 하는 이유 4가지**(p.19): 소요 시간 예상 / 문항 정교화 / **허용 답안 범위 판단** / 평가 요소 적합성 수정.
- **채점기준 3요소**(p.20): 채점 요소 / 채점 척도·배점 / **수행 특성 진술문**.
- **성취수준별 학생 수행 특성 예측**(p.21) 및 그 한계 원문: "문항이 … 성취기준의 일부를 평가 요소로 설정한 경우에는 **해당 문항만으로 모든 성취수준을 정확하게 판단하기는 어렵습니다.**"
- **채점자 신뢰도**(p.22): 채점자 간/내 신뢰도 정의, 표본 가채점, 후광 효과 배제, "**논술형은 서술형보다 채점자 간 차이가 상대적으로 많이 발생**" → 복수 채점 + 채점자 협의.
- **채점 및 피드백 3단 서식**(p.23): 학생 답안 예시 → 채점 결과 예시(체크 ✔ 열) → 학생 개별 피드백 예시.
→ [[서논술형-문항개발-5단계절차]], [[평가요소-도출-원리]], [[발문과-반응지시어]]

### 평가 도구 정보표 서식 (p.25 등)
항목 9개: 학교급 / 과목 / 학년 / 영역·단원 / **평가 유형**(지필·수행) / **문항 유형**(서술형·논술형) / **성취기준 및 성취수준**(코드·진술문 + A~E) / **성취기준 기반 평가 요소** / **평가 도구 개발 취지**.
수행평가형은 '1. 평가 도구 정보표' 뒤에 **'2. 교수·학습 활동 및 평가 계획'**(차시별 교수·학습 활동 + 평가 활동, 형성평가 → 교사 피드백 → 총괄 수행평가)을 삽입(p.68).
⚠ 자료집 전체에 **'이원목적분류표'라는 용어와 서식이 등장하지 않는다**(전수 검색 확인). 정보표 + 채점기준 + 성취수준별 수행 특성 3종이 이를 대체·확장한다.

### 채점기준표 양식·배점·부분점수
- 열 구성 3종: 【A】 채점 요소|점수|수행 특성(p.20) / 【B】 문항|채점 요소|점수|수행 특성(Ⅲ장 대부분) / 【C】 B + ✔ 열(채점 결과 예시형).
- 배점 규칙: 소문항 배점 = 채점 요소 최고 척도값 / 총점 = 소문항 합 / 척도 2~4단계 + 0점 / **0점 = "무응답 또는 기타 오답" 무예외**.
- **부분점수 4유형**: ① 위계형(01-(1) p.28) ② **체크리스트 개수형**(09-(2) p.95, 14-(2) p.156 — "위 4가지 수행 특성 중 2가지만 만족함") ③ 복수 경로 인정형(06-(2) p.63 "경우1/경우2") ④ 요소 결합형(18-(3)① p.208).
→ [[채점기준표-작성지침]]

### '채점 시 유의점' 코퍼스 (사례 15건, p.29 외)
- **분류 A 정답 인정**: 밑의 범위 설명(01 p.29), 제시문 한 등식만 이용(01 p.29), **연쇄 오류 구제**(04 p.49), 귀류법 대안 인정(07 p.72), 우회 풀이 인정하되 "평가 목적인 경우 일부 감점"(03 p.42).
- **분류 B 표현 미흡 구제**: "표현이 다소 부족하더라도 결과를 도출한 경우"(11 p.118) 등 10건.
- **분류 C 교과협의회 재량**: "다양한 답지가 나올 수 있으므로 **교과협의회를 통해 세부기준을 정할 수 있습니다**"(06 p.63) 등 8건.
- **분류 D 감점·무득점**: ★"**직관에 따라 옳은 관계식을 구하였더라도 그 과정에 대한 설명이 없는 경우 점수를 주지 않습니다.**"(05 p.56) / **지정 도구 사용 강제**(09 p.97) / **부분 구간만 다룬 불완전 논증 감점**(09 p.97) / **역량 입증 vs 계산 오류 분리**(17 p.196) / **필수 키워드 명시 요구**(18 p.211) / **공식 적용 ≠ 원리 설명**(18 p.211) / **자료 연계 필수**(18 p.211).

### 사전과제 직접 전이 포인트
- 사례 01 **지수의 확장**(p.25–31)은 **수 체계 확장**이라는 점에서 중2 유리수 단원과 동형. 3단 발문 구조: **오류 진단·교정형 → 제시문 근거 정당화형 → 적용·계산형**.
- 단원 목표(유리수 ⟺ 유한소수 또는 순환소수)를 문항화하는 발문 4유형(§16-2): ① 오류 진단·교정형(01-(1) p.26, 14-(1) p.153) ② 제시문 근거 정당화(증명)형(01-(2) p.26, 06-(3) p.61) ③ **명제의 참·거짓 판별 + 반례형**(08-(4) p.78, 09-(4) p.93) ④ **존재성 판단형**(07-(1) p.69).
- 도움 자료(p.212): 학생평가지원포털 **stas.moe.go.kr**(성취기준 검색, 서·논술형 평가 도구 검색, 현장중심 평가 도구, 연수 자료), NCIC **ncic.re.kr**(교육과정 원문·해설서, 평가기준). 중학교 자료는 동일 포털의 '중학교' 경로.

### ⚠ 본 자료집에서 확인되지 않는 항목 (§16-4 — 집합연수 요청 사항 후보)

3. 문항 검토 체크리스트 / 이원목적분류표 서식 — 부재.
4. 동료평가·자기평가 도구 양식 — 문구만 등장(p.68), 서식 없음.

# 서·논술형 문항 개발 5단계 절차

전북 연수자료(윤희정, 2026, p.28)가 제시하는 논술형 평가 문항 제작의 중심 틀은 **① 성취기준 및 성취수준 확인하기 → ② 평가 요소 선정하기 → ③ 평가 방법 선택하기 → ④ 문항 작성하기 → ⑤ 수행 수준(채점 기준) 작성**의 5단계다. KICE 자료집(ORM 2025-91-2)은 같은 작업을 **4단계(평가 계획 / 평가 문항 개발 / 채점기준 개발 / 채점 및 피드백)**로 묶고 '채점·피드백'을 절차 안으로 끌어들이며(p.16–23), 경기 자료집(2025 경기 논술형 평가 Ⅱ)은 절차를 명시하지 않는 대신 **서식 항목 순서 자체가 절차**로 기능한다(PDF pp.12~15). 세 자료를 겹치면 실질 절차는 **[성취기준·성취수준 분석] → [평가요소 선정] → [평가유형·문항유형 결정] → [문항(발문·자료·조건) 작성 + 예시답안] → [채점기준 개발] → [상호검토·채점·피드백]**의 6국면으로 정리된다.

## Details

### 1. 세 자료의 절차 대조표

| 국면 | 전북 p.28 (5단계) | KICE p.16–23 (4단계) | 경기 pp.12~15 (서식 역산 6단계) |
|---|---|---|---|
| 성취기준·성취수준 분석 | ① 성취기준 및 성취수준 확인하기 (p.30~31) | 【1단계】 평가 계획 — ◇성취기준 및 성취수준 분석하기 (p.16) | 2. 성취기준 선정 + 성취기준별 성취수준 5단 기술 (❻❼) |
| 평가요소 선정 | ② 평가 요소 선정하기 (p.32~36) | 【1단계】 — ◇평가 요소 선정하기 (p.17) | 3. 평가 요소 도출 (❽) |
| 평가유형·문항유형 결정 | ③ 평가 방법 선택하기 (p.40~41) | 【1단계】 정보표의 '평가 유형/문항 유형' 결정 (p.17, p.25) | 1·4. 학교급·과목·영역 확정 + 평가 방법(❹)·평가 시간(❺) |
| 문항 작성 | ④ 문항 작성하기 (p.42~43, 48~52) | 【2단계】 평가 문항 개발 — ◇평가 문항 개발하기 / ◇예시 답안 작성하기 (p.18–19) | 5. 문항 작성(발문·조건·문항 자료, ❷) + 제작 의도(❾)·수업–평가 연계 주안점(❿) |
| 채점기준 작성 | ⑤ 수행 수준(채점 기준) 작성 (p.58, 71~72) | 【3단계】 채점기준 개발 — ◇채점기준 개발하기 / ◇성취수준별 학생 수행 특성 예측하기 (p.20–21) | 6. 채점기준표(❹❺❻❼) |
| 검토·채점·피드백 | (5단계 이후) 교과협의회 상호 검토·수정 (p.73), 채점자 신뢰도 (p.78~79) | 【4단계】 채점 및 피드백 (p.22–23) — **독립된 단계로 승격** | 채점 시 유의점(❽) / 피드백 시 유의점(❾) — 문항마다 붙는 고정 항목 |

> **핵심 차이**: 전북 5단계는 '채점기준 작성'에서 절차가 끝나고 검토·피드백은 후속 활동으로 서술된다(p.73~79). KICE는 **채점·피드백을 4단계로 승격**시켜 절차 안에 넣었다(p.22–23). 경기는 절차를 안 쓰는 대신 **'채점 시 유의점'과 '피드백 시 유의점'을 모든 문항의 필수 서식 항목**으로 못 박았다(PDF p.15 ❽❾). 사전과제에서 5단계를 쓰되 "⑤ 이후 검토·채점·피드백"을 반드시 한 문단 덧붙이면 세 자료 모두와 정렬된다.

### 2. 단계별 산출물과 점검 질문

#### ① 성취기준 및 성취수준 확인하기
- **반드시 산출할 것**
  - 성취기준 코드 + 진술문 (전북 p.30, KICE p.16, 경기 ❼)
  - 성취기준별 성취수준 A~E(또는 3수준) 진술문 (전북 p.30~31, KICE p.16, 경기 ❻)
  - 성취수준을 **지식·이해 / 과정·기능 / 가치·태도** 3범주로 분해한 표 (전북 p.30 중1 [9수01-05] 예시, p.31 고1 [10공수1-02-02] 예시)
  - 수업 목표·수업 요소와 평가 목표·평가 요소가 다룰 **내용의 범위와 수준** (전북 p.31)
- **성취수준 진술의 위계 조절 어휘 패턴** (KICE p.16, [10공수1-04-02] 사례): **A "다양한" → B (무표) → C "간단한" → D (하위 행동만) → E "안내된 절차에 따라"**. 중2 단원에 그대로 전이 가능한 어휘 골격.
- **점검 질문**
  1. 평가할 성취기준을 확정하고 그 성취기준별 성취수준(A~E)을 분석했는가? (KICE 체크 A1, p.16)
  2. 성취수준 진술이 A→E로 내려가며 **무엇이 줄어드는가**(범위/복잡도/자립도)를 말할 수 있는가? (KICE p.16 위계 어휘)
  3. 2022 개정 교육과정 용어로 '성취수준'을 쓰고 있는가? (2015 개정은 '평가기준' — 경기 ❻ 각주)

#### ② 평가 요소 선정하기
- **반드시 산출할 것**: 성취기준 분석에서 도출한 평가 요소 목록. 자세한 도출 규칙은 [[평가요소-도출-원리]] 참조.
- **점검 질문**
  1. 평가 요소가 **성취기준 도달의 증거**로서 관찰 가능한 행동으로 기술되었는가? (전북 p.39, KICE p.17 체크 A3)
  2. 서·논술형 평가에 **적합한** 평가 요소인가(계산 확인만으로 끝나지 않는가)? (KICE p.16 체크 A2)
  3. 지식·이해 / 과정·기능 / 가치·태도의 관점이 반영되었는가? (KICE p.17 체크 A4, 경기 ❽)

#### ③ 평가 방법 선택하기
- **반드시 산출할 것**
  - 평가 유형: **지필평가 / 수행평가** (전북 p.40~41, KICE 정보표 p.25, 경기 ❹ "지필평가 논술형 혹은 수행평가 논술형")
  - 문항 유형: **서술형 / 논술형** (KICE 정보표 p.25) — 구분 기준은 [[서술형과-논술형의-구분]] 참조
  - 예상 평가 시간 (경기 ❺). 경기 실측: 지필 10~20분·5~10점 / 수행 25~40분·12~20점 (경기 §5-1 중학교 10문항 개관표)
- **난이도 목표 진술**: "각 수준에 해당하는 학생 1/2이(또는 2/3이) 만점을 받을 수 있도록 개발"(전북 p.41 말풍선).
- **점검 질문**
  1. 학습 내용·평가 요소에 적절한 유형인가? 개념 대응은 선택형, **해석·설명은 논술형**이라는 대응이 지켜지는가? (전북 p.41)
  2. 평가 유형(지필/수행)과 문항 유형(서술형/논술형)을 둘 다 결정했는가? (KICE 체크 A5)
  3. 수행평가라면 **교수·학습 활동 및 평가 계획**(차시별 흐름 + 형성평가 + 교사 피드백)을 함께 작성했는가? (KICE p.68 서식, 경기 ❿)

#### ④ 문항 작성하기
- **반드시 산출할 것**
  - **자료(보기) + 발문[평가 요소 + 반응 지시어] + 조건**의 3요소 문항 (전북 p.52, 출처: 박혜영 외 2019 『단위학교의 서·논술형 평가 내실화 방안』; KICE p.18; 경기 ❷)
  - 총괄 배점 `[N점]`과 소문항 배점 `(N점)` (KICE p.18, p.26; 경기 서식 예시 "※ 다음 글을 읽고 물음에 답하시오. [총20점]", PDF p.14)
  - **예시 답안** — KICE는 문항 개발 단계에서 **반드시 함께 작성**하도록 명시(p.19)
  - 출제 의도 / 평가 도구 개발 취지 (KICE 정보표 p.25, 경기 ❾)
- **예시 답안을 문항 개발 단계에서 써야 하는 이유 4가지** (KICE p.19 원문): ⑴ 문항 해결 소요 시간을 예상할 수 있다 ⑵ 문항을 보다 정교하게 수정할 수 있다 ⑶ 의도한 정답 외 **허용 답안의 범위**를 판단할 수 있다 ⑷ 평가 요소에 더 적합하도록 문항을 수정할 수 있다.
- **점검 질문**
  1. **발문만으로** 학생이 작성해야 하는 응답의 내용과 범위가 명확한가? 아니라면 조건을 추가했는가? (KICE p.19 체크 B2·B3)
  2. **조건이 과다하거나 모호하지 않은가?** (KICE p.19 체크 B4) 조건에 정답 전체 또는 일부가 암시되지 않는가? (전북 p.43)
  3. 자료와 발문이 긴밀히 연관되며, 문제해결 시간에 비해 정보가 과다하지 않은가? (전북 p.43, KICE 체크 B5)
  4. 소문항 간 연계(앞 결과를 뒤에서 사용) 구조가 있다면 **연쇄 오류 처리 방침**을 정했는가? (KICE 체크 B7 / 근거 p.49, p.63, p.118, p.167)
  5. 예시 답안을 썼고, 그 결과 허용 답안 범위를 판단했는가? (KICE 체크 C1~C4)

#### ⑤ 수행 수준(채점 기준) 작성하기
- **반드시 산출할 것**
  - 채점기준표: **문항 | 평가 요소 | 채점 요소 | 배점 | 수행 수준(채점기준)** 5열 (전북 p.26·58~59·81, 경기 §4-1) 또는 **채점 요소 | 점수 | 수행 특성** 3열 (KICE p.20). 상세는 [[채점기준표-작성지침]] 참조
  - **0점: 무응답 또는 그 외 오답** 급간 (전북 p.26·59·81, KICE 전 사례 공통)
  - 채점 시 유의점 = 인정답안·부분점수·감점·무득점 조항 (KICE 사례 15건, 경기 ❽)
  - 성취수준별(A/B–C–D/E) 예상 점수 구간과 학생 수행 특성 (KICE p.21)
- **원리**: "정확한 수행수준(채점기준) 마련 → 논술형 평가의 **신뢰도** 확보 / 평가 문항 〈조건〉에 포함된 제한 요소들을 수행수준에 포함 → **공정성** 확보"(전북 p.71).
- **점검 질문**
  1. 채점기준에 **채점 요소 / 채점 척도·배점 / 수행 특성 진술문** 3요소가 모두 있는가? (KICE p.20 체크 D1)
  2. 채점 요소를 평가 요소 **+ 문항의 〈조건〉**까지 반영해 구체화했는가? (전북 p.59 각주, KICE p.20 체크 D2)
  3. 0점 급간을 명시했는가? (KICE 체크 D4)
  4. 성취수준별 예상 점수 구간을 예측하고, **문항 하나로 모든 성취수준을 판단할 수는 없다**는 한계를 인지했는가? (KICE p.21 체크 D5)

#### ⑥ (KICE 4단계 / 전북 후속) 상호 검토 · 채점 · 피드백
- **반드시 산출할 것**
  - 교과협의회 상호 검토·수정 기록, 예시답안·인정답안 범위 설정 (전북 p.73, KICE p.19 체크 E1)
  - 표본 답안 **가채점** 결과 비교 기록 (전북 p.79, KICE p.22 체크 E4)
  - 채점 결과 예시(채점기준표 + ✔ 열) 및 **학생 개별 피드백** 문안 (KICE p.23)
  - 피드백 시 유의점 (경기 ❾, KICE 각 사례 말미)
- **점검 질문**: 검토 항목의 전체 목록은 [[채점기준표-검토기준]] 참조.
  1. 채점자 간 신뢰도(복수 채점자 점수 일치도)를 표본 가채점으로 확인했는가? (전북 p.79, KICE p.22)
  2. 채점자 내 신뢰도 — 후광 효과 배제, 일관된 엄격성, 적절한 휴식? (전북 p.79, KICE p.22)
  3. 논술형은 서술형보다 채점자 간 차이가 크다는 전제 위에서 **복수 채점 + 채점자 협의**를 계획했는가? (KICE p.22)

### 3. 절차를 관통하는 산출물 계보

```
[성취기준] + [성취기준별 성취수준 A~E]
      ↓ 분석
[성취기준 기반 평가 요소]        ← 1~2단계 산출물 (문항 개발 前)
      ↓ 문항화 (자료 + 발문 + 조건)
[문항] + [예시 답안]             ← 4단계 산출물
      ↓ 조건 반영
[채점 요소]                      ← 5단계 산출물 (문항 개발 後)
      ↓
[배점(척도)] + [수행 수준 진술문] + [0점 급간]
      ↓
[성취수준별 점수 구간 + 학생 수행 특성 예측] → [채점] → [개별 피드백]
```
(KICE §5-1 연결 논리, p.16→17→18→20→21→23 / 전북 p.28·p.29 성취기준→평가요소→평가문항 변환 모델)

### 4. 전북 자료의 위치 규정 — 학교 수준의 큰 흐름

5단계는 고립된 절차가 아니라 다음 흐름 안에 위치한다(전북 p.28):
**교육과정 운영 계획**(성취기준·성취수준 분석 → 교수·학습 및 평가 계획 수립) → **교수·학습 및 평가**(교수·학습 측: 자료 개발·학생 참여형 수업 / 평가 측: 평가 과제 개발 · 수행 수준(채점기준) 개발 · 평가 실행 · 평가 결과 채점) → **피드백 ↔ 기록**.

### 5. 설계 방향 4대 원리 (전북 p.21~23)
① **미래 역량을 함양하는 평가** — 학습 과정과 개인 성취도를 바탕으로 '성장' 중시, 실생활 맥락 역량 평가.
② **깊이 있는 수업과 연계한 평가** — 핵심아이디어 중심으로 내용 요소를 유기적으로 연계한 수업에서의 학습 경험이 논술형으로 이어지도록.
③ **성취기준에 근거한 평가 + 수행 수준이 명확한 평가** — 평가요소별 수행수준이 출제 의도·발문·조건과 유기적으로 연결되어 "'무엇'을 묻고 학생들이 '어떻게' 작성해야 하는가가 명확"(p.22).
④ **피드백과 성장을 일으키는 평가** — 논리적 오류를 바로잡고 사고 확장을 촉진하는 구체적 피드백.

경기 자료집의 대응 진술은 **3대 철학**이다(PDF p.7): 실제적 맥락에 기반한 평가('교실을 넘어 세상과 만나다') / 다양한 관점을 여는 평가('생각의 날개를 달다') / 생각에 대한 생각을 키우는 평가('배움의 디딤돌이 되다').

## Counter-Arguments and Gaps

> [!WARNING] 단계 수의 불일치
> 전북 5단계(p.28) ↔ KICE 4단계(p.16–23) ↔ 경기 무절차(서식 순서만, PDF pp.12~15). 세 자료가 같은 작업을 다른 개수로 자른다. **단계 번호를 인용할 때는 반드시 자료명을 병기**해야 하며, "표준 5단계"라는 표현은 전북 자료 한정임을 밝혀야 한다.

- **'평가 방법 선택'의 위치가 다르다.** 전북은 3단계로 독립시켰지만(p.40~41), KICE는 1단계 '평가 계획' 안에 흡수했고(p.17 평가 유형·문항 유형), 경기는 서식 ❹ 항목으로만 존재한다(PDF p.13). 사전과제에서 3단계를 독립 서술하면 전북 정렬, 1단계에 흡수하면 KICE 정렬이 된다 — 둘 중 하나를 택하고 근거를 밝힐 것.
- **'예시 답안 작성'이 전북 5단계 어디에도 명시되지 않는다.** KICE는 이를 2단계의 정식 산출물로 못 박고 그 이유 4가지까지 제시하지만(p.19), 전북 자료는 채점기준 검토 항목에서 "예시답안·인정답안 등의 범위를 설정"(p.73)이라고만 언급한다. **4단계에 예시답안 작성을 명시적으로 추가하는 것은 KICE 근거로 보완한 것**임을 밝혀야 한다.
- **난이도 목표치의 출처 검증 미완.** "각 수준에 해당하는 학생 1/2(또는 2/3)이 만점"(전북 p.41 말풍선)의 근거 연구는 자료에 제시되지 않았다. KICE·경기 어디에도 대응 진술이 없다.
- **경기의 '문항 제작 절차 6단계'는 원문이 아니다.** 경기 raw 소스 §2-2-(3)이 "자료집 서식 순서 기반 재구성 — 원문 명시 아님"이라고 명시한다. 인용 시 재구성물임을 밝힐 것.
- **중2 [유리수와 순환소수] 직접 사례 부재.** KICE 자료집은 고등학교 일반 선택 과목 전용이며 '수와 연산' 사례는 01 지수의 확장뿐(KICE §16-4). 경기 자료집은 중학교 10문항 전부 1학년, '수와 연산' 영역 0건(경기 §5-0). **5단계 절차를 중2 수와 연산에 적용한 완성 사례는 세 자료 어디에도 없다** — 집합연수 요청 사항 후보.

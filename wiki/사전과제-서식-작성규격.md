# 사전과제 서식(HWPX 표1~표5) 칸별 작성 규격

전북 2026 서·논술형 평가 심화과정 직무연수 사전과제 HWPX 서식은 **표 5개**로 구성된다. 각 칸이 요구하는 내용·문체·분량과, 특히 **'채점 기준 초안'이 〈평가 요소〉·〈채점 기준〉 두 칸뿐이라는 제약** 아래 표준 5열 채점기준표를 어떻게 압축해 담을지의 서식을 규정한다. 근거는 연수 실습 양식 7종([[연수-실습양식-요약]]), 전북 연수자료(마루고 윤희정, 85쪽), KICE 자료집, 경기 자료집.

---

## 1. 서식 전체 구조 (HWPX 실제 칸 구조 그대로)

| 표 | 칸 구조 |
|---|---|
| **[표1]** 인적사항 | 교과 \| (값) \| 학교급 \| (값) // 소속 \| (값) \| 성명 \| (값) |
| **[표2]** ① 기존 평가 문항 제시 | 평가 유형 \| (값) / 관련 단원 \| (값) / 성취기준 \| (값) / 기존 평가 문항 \| (값) |
| **[표3]** ② 기존 평가 분석 | 분석 요소 \| 내용 // 성취기준 연계성 / 학생 사고 수준 / 학생 응답 특성 / 개선 필요 요소 |
| **[표4]** ③ 개선 방향 및 재구성 | 개선 방향 \| (값) // 서·논술형 평가 문항 재구성 \| (값) // 채점 기준 초안 → **평가 요소 \| (값)**, **채점 기준 \| (값)** |
| **[표5]** ④ 집합연수 요청 | 집합연수에서 중점적으로 도움받고 싶은 내용 \| (값) |

> [!NOTE] 구조상의 핵심 제약
> 표4의 '채점 기준 초안'은 **2칸(평가 요소 / 채점 기준)**뿐이다. 반면 이 연수가 표준으로 삼는 채점기준표는 **5열**【문항 | 평가 요소 | 채점 요소 | 수행 수준(채점기준) | 배점】이다(실습5. 채점기준표.xlsx `A2:E2`; 전북 연수자료 p.26·58·59·81). 따라서 5열 → 2칸 **압축 규칙**이 반드시 필요하다. §5 참조.

## 2. [표1] 인적사항 — 작성 규격

| 칸 | 쓸 내용 | 문체 | 분량 |
|---|---|---|---|
| 교과 | `수학` | 명사 단독 | 1어절 |
| 학교급 | `중학교` (필요 시 `중학교 2학년`) | 명사 단독 | 1~2어절 |
| 소속 | 학교 정식 명칭 | 명사구 | 1행 |
| 성명 | 실명 | — | 1행 |

- 실습1 양식(`실습1.성취기준 및 수준 분석.xlsx` 각 시트 `B1`)은 작성자 이름을 시트 최상단에 두는 구조이며, 실습2 `단원설계(실습)` 시트는 `이름 (                       )` 기입란을 학년 열마다 둔다. 사전과제 표1은 이 두 관행을 하나로 합친 칸이다.

## 3. [표2] ① 기존 평가 문항 제시 — 칸별 규격

| 칸 | 쓸 내용 | 문체 규격 | 분량 규격 | 원문 근거 |
|---|---|---|---|---|
| **평가 유형** | ⑴ 평가 종류(지필평가/수행평가) + ⑵ 문항 유형(선택형/단답형/서술형/논술형)을 **둘 다** 표기. 예: `지필평가(1차) — 서술형` | 명사구 병기, 문장 아님 | 1행(20자 내외) | 전북 p.12~14 유형 분류체계, p.16 서술형↔논술형 구분 / KICE 평가 도구 정보표「평가 유형」+「문항 유형」(p.25) |
| **관련 단원** | 교과서 단원명 + 영역명 병기. 예: `Ⅰ. 수와 식의 계산 > 1. 유리수와 순환소수 (수와 연산)` | 명사구 | 1행 | 개념기반 매핑 시트 `A2 = 유리수와 순환소수`, 영역=수와 연산 |
| **성취기준** | **코드 + 진술문을 원문 그대로**. 임의 축약·재진술 금지. `[9수01-06] 순환소수의 뜻을 알고, 유리수와 순환소수의 관계를 설명할 수 있다.` | 원문 인용 | 1~2행 | 매핑(2월-중2) `C2` / 2022 개정 성취수준 자료 인쇄면 20면 |
| **기존 평가 문항** | 실제 출제했던 문항을 **발문·자료·조건·배점까지 그대로 전재**. 요약하지 말 것. 구조는 `자료(보기) + 발문[평가 요소 + 반응 지시어] + 조건 + [n점]` | 문항 원문 인용(경어체 아님, 시험지 문체 그대로) | 5~15행. 자료(표·그래프)는 표로 재현 | 전북 p.52 문항 구조식(박혜영 외 2019) / 실습5 `고`·`중` 시트 임베드 이미지의 문항 전재 방식 |

**작성 팁**
- 하위문항이 있으면 `1-1.`, `1-2.` 번호와 각 배점을 살릴 것(실습5 `고` 시트 문항 1-1[3점]/1-2[4점] 방식).
- 기존 문항이 선택형·단답형이었다면 그 사실 자체가 ②의 분석 재료가 되므로 숨기지 말 것. 전북 p.6~7의 진단 축("답만 쓰는 평가 / 결과만 확인하는 평가")을 그대로 적용할 근거가 된다.

## 4. [표3] ② 기존 평가 분석 — 4개 분석 요소의 칸 규격

각 칸의 **논증 근거와 서술 틀**은 [[기존문항-분석-관점]]에서 상세히 다룬다. 여기서는 서식상의 문체·분량 규격만 규정한다.

| 분석 요소 | 문체 규격 | 분량 규격 | 반드시 포함할 것 |
|---|---|---|---|
| **성취기준 연계성** | "~를 평가하는 문항이나, ~는 평가하지 못한다." 형태의 **판정문 + 근거문** | 3~5문장 | 성취기준 3범주(지식·이해/과정·기능/가치·태도) 중 무엇이 커버되고 무엇이 누락되었는지 **범주명을 명시** |
| **학생 사고 수준** | "이 문항이 요구하는 인지 수준은 ~이다."의 **수준 명명문 + 근거문** | 3~5문장 | 명시적 틀 1개 이상 사용(성취수준 A~E / 수학 인지수준 계산·이해·추론·정당화 / Bloom / DOK) — [[기존문항-분석-관점]] §2 |
| **학생 응답 특성** | "~한 학생이 다수였다 / ~오류가 반복되었다"의 **관찰 진술문**(과거형) | 3~6문장 | 실제 오답 유형 2~3가지 + (가능하면) 대략적 비율. 오개념은 인용부호로 학생 말투 그대로 재현 |
| **개선 필요 요소** | "~하므로 ~해야 한다"의 **결손 지적 + 처방 예고문** | 3~5문장, 또는 `①②③` 번호 목록 | 발문(반응지시어)·조건·자료·채점기준 4축 중 어디가 문제인지 지목. ③의 개선 방향과 **1:1로 대응**되게 쓸 것 |

> 4칸은 서로 독립된 감상문이 아니라 **하나의 논증 사슬**이다: 연계성(무엇을 못 재는가) → 사고 수준(어느 수준에 머무는가) → 응답 특성(그 결과 학생 답안이 어떠했는가) → 개선 필요 요소(따라서 무엇을 바꿔야 하는가).

## 5. [표4] ③ 개선 방향 및 재구성 — 칸별 규격

### 5-1. 「개선 방향」 칸

| 항목 | 규격 |
|---|---|
| 문체 | "~하도록 재구성한다 / ~로 바꾼다"의 **설계 선언문**(현재·미래 시제) |
| 분량 | 5~8문장 또는 `①~⑤` 번호 목록 |
| 필수 구조 | 전북 연수자료 p.28의 **5단계 절차 순서 그대로** 서술: ① 성취기준·성취수준 확인 → ② 평가 요소 선정 → ③ 평가 방법 선택 → ④ 문항 작성 → ⑤ 수행 수준(채점 기준) 작성 |
| 필수 언급 | ⑴ 반응 지시어를 무엇에서 무엇으로 바꾸는가([[반응지시어-수정사례]]), ⑵ 조건을 어떻게 한정하는가(정답 암시 금지, 전북 p.43), ⑶ 난이도 목표("각 수준에 해당하는 학생 1/2 또는 2/3이 만점", p.41) |
| 금지 | '학생 참여를 높이겠다' 류의 수업 개선 일반론. 반드시 **평가도구 설계** 수준에서 진술 |

### 5-2. 「서·논술형 평가 문항 재구성」 칸

| 항목 | 규격 |
|---|---|
| 구조 | **자료(보기) + 발문[평가 요소 + 반응 지시어] + 조건 + [배점]** (전북 p.52) |
| 문체 | 실제 시험지에 그대로 인쇄할 수 있는 **완성 문항 문체**. 설명·해설을 섞지 말 것 |
| 분량 | 10~20행. 하위문항은 `(1) (2) (3)`으로 분할하고 각 배점 표기 |
| 발문 어미 | 경기 자료집 실사용 관행에 맞춰 **`~을 …하고, 그 이유를 ○○을 이용하여 설명(서술)하시오.`** 형태로 마감. 수행 동사(구하다/판단하다/판별하다/찾다)는 앞부분에 둔다 |
| 조건 | 2~3개. "'순환마디'라는 표현을 사용할 것", "기약분수의 분모를 소인수분해하여 나타낼 것"처럼 **핵심 개념어 사용과 표현 형식**을 한정. 조건의 제한 요소는 반드시 채점 기준에 반영(p.52·71 — 공정성 확보 논리) |

### 5-3. ★「채점 기준 초안」 2칸 압축 서식 (이 서식의 최대 난점)

**원리**: 표준 5열【문항 | 평가 요소 | 채점 요소 | 수행 수준(채점기준) | 배점】중
- `문항`·`평가 요소`·`채점 요소` → **〈평가 요소〉 칸**에 번호 붙인 **명사형 어구**로 압축
- `수행 수준(채점기준)`·`배점` → **〈채점 기준〉 칸**에 **요소별 배점 급간 진술**로 압축

#### (1) 〈평가 요소〉 칸 서식

```
1. (지식·이해) ○○○ 판정하기
2. (과정·기능) ○○○ 과정 설명하기
3. (과정·기능) ○○○ 관계 서술하기
4. (가치·태도) ○○○ 인식하기          ← 선택(수행평가로 확장할 때만)
```

| 규칙 | 내용 |
|---|---|
| 개수 | **3~4개**. 2개 이하면 논술형의 다면성이 안 드러나고, 5개 이상이면 배점 급간이 1점 단위로 쪼개져 변별이 무너짐(전북 p.82 "채점 요소별 배점이 적어 수행 수준 차이를 점수에 반영하기 어려운 경우") |
| 형태 | **반드시 명사형 어구(`~하기`)**. 문장형("~할 수 있다") 금지 — 전북 p.32 "학생이 주도적으로 반응할 수 있는 지시어를 '명사형 어구'로 사용"(예: 그래프 해석하기, 관계식 구하기, 두 변수의 관계 설명하기) |
| 범주 병기 | 각 어구 앞에 **(지식·이해)/(과정·기능)/(가치·태도)** 를 괄호로 붙임. 근거: `평가 설계(3학년B)` `B11` = "1. (지식·이해) 수 체계 설명하기 …", `평가 설계(1학년A)` `B11` 동일 관행 |
| 심화 표기(선택) | `무리수의 개념(지식이해_설명)`처럼 **범주_이해의 측면**을 함께 다는 방식도 원문에 있음(`평가 설계(3학년B)` B14:D30). 이해의 6측면(설명/해석/적용/관점/공감/자기지식)과 정렬됨 |
| 도출 근거 | 성취기준 분석에서 도출. 문항의 〈조건〉을 반영해 세분화된 것은 엄밀히는 '채점 요소'이나, 2칸 서식에서는 평가 요소 칸에 흡수시키고 채점 기준 칸의 급간 진술에서 조건 충족 여부로 드러낸다(KICE p.20 "채점 요소는 … 추가·통합·세분화될 수 있음") |
| 순서 | 문항 내 하위문항 순서 = 평가 요소 번호 순서로 일치시킬 것 |
| 배점 병기 | 각 어구 끝에 `[3점]`처럼 배점을 달면 채점 기준 칸과의 대응이 즉시 보임(권장) |

#### (2) 〈채점 기준〉 칸 서식 — 요소별 배점 급간 진술

```
[평가요소 1] (3점)
 3점 — (최고 급간 진술)
 2점 — (중간 급간 진술)
 1점 — (하위 급간 진술)
 0점 — 무응답 또는 그 외 오답

[평가요소 2] (4점)
 4점 — …
 3점 — …
 2점 — …
 1점 — …
 0점 — 무응답 또는 그 외 오답
```

| 규칙 | 내용 | 근거 |
|---|---|---|
| 블록 단위 | **평가 요소 1개 = 진술 블록 1개**. 블록 머리에 `[평가요소 n] (배점 합계)` | 실습5 5열 구조의 세로 병합(`C3:C5`,`C6:C8`,`C9:C11`)을 세로 텍스트로 편 것 |
| 급간 수 | 3~5급간. 만점이 2점이면 3급간(2/1/0), 3점이면 4급간(3/2/1/0), 4점 이상이면 5급간까지 | 실습5 `고` 문항1=4급간, 문항2=5급간, `중`=채점요소 3개×3급간 |
| 배점 표기 | 항상 **`n점` 문자열**(숫자만 쓰지 않음) | 실습5 원문 셀값 규칙 |
| 0점 진술 | **"무응답 또는 그 외 오답"으로 고정**. 변형 금지(KICE는 "무응답 또는 기타 오답", 전북·실습5는 "무응답 또는 그 외 오답" — 전북 연수 서식이므로 후자 채택) | 전북 p.26·59·81, 실습5 두 시트 공통, KICE 18개 사례 전부 |
| 최고 급간 문형 | "~을 정확히 …하고, ~을 (타당하게/논리적으로/정합성 있게) 설명(서술)함." | 실습5 `고` `D3`, `중` `D3` |
| 중간 급간 문형 | "~은 맞게 …했으나, ~에 대한 설명이 부족하거나 논리적 오류가 있음." / OR 병기: "~은 타당하나 ~설명이 없음. **또는** ~했으나 ~이 비현실적임." | 실습5 `고` `D4`, `중` `D8` |
| 하위 급간 문형 | "~이 틀렸거나, 문제의 의도와 무관한 서술을 함." | 실습5 `고` `D5` |
| 종결 어미 | 전부 **"~함."** (관찰 사실 기술체). "~할 수 있습니다" 체는 학생·학부모 피드백용이므로 채점기준표에는 쓰지 않음 | KICE p.21 문체 규칙 |
| 배타성 | 급간 진술끼리 겹치지 않게. 실패 사례: '구조의 명확성'과 '구조의 논리성' 진술이 겹침(전북 p.76) | 전북 p.73~77 검토 기준 |
| 포괄성 | 개수 세기만으로 급간을 나누지 말 것("3가지=5점, 2가지=4점 …" 형 오류, 전북 p.77) | 동상 |
| 정도 부사어 | '대체로', '다소' 남용 주의 — 반드시 **무엇이 빠졌는지**를 함께 명시 | 전북 p.82 |
| 부분점수 | "완전한 답이 아니더라도 부분적으로 올바른 내용이나 논리를 제시할 경우 부분 점수를 부여함"을 칸 말미에 1행 명문화 | 전북 p.80 |
| 채점 유의 사항 | 출제 의도를 못 박아야 할 때 블록 뒤에 `※ 채점 유의:` 1~2행 추가 가능 | 전북 p.72 ⑥ |

#### (3) 중2 [유리수와 순환소수] 적용 예시 (도출 예시 — 원문 인용 아님)

> 아래는 위 규격을 이 단원에 적용해 만든 **작성 견본**이다. 성취기준·성취수준 문구만 원문이고 나머지는 도출이다.

**〈평가 요소〉 칸 견본**

```
1. (지식·이해) 기약분수의 분모의 소인수를 근거로 유한소수·순환소수 판정하기 [3점]
2. (과정·기능) 순환소수를 분수로 나타내는 과정을 근거를 들어 설명하기 [4점]
3. (과정·기능) '유리수 ⟺ 유한소수 또는 순환소수'의 동치 관계를 두 방향으로 서술하기 [3점]
```

**〈채점 기준〉 칸 견본**

```
[평가요소 1] (3점)
 3점 — 기약분수로 고친 뒤 분모를 소인수분해하여, 소인수가 2와 5뿐인지 여부를
        근거로 유한소수·순환소수를 정확히 판정하고 그 이유를 서술함.
 2점 — 판정은 옳으나 기약분수화 또는 분모의 소인수분해 근거 서술이 빠져 있음.
 1점 — 판정만 옳게 쓰고 이유를 서술하지 못했거나, 판정이 틀림.
 0점 — 무응답 또는 그 외 오답

[평가요소 2] (4점)
 4점 — 10의 거듭제곱을 곱해 소수 부분을 소거하는 과정을 식으로 나타내고,
        각 단계가 성립하는 이유를 논리적으로 설명하여 분수 표현을 정합성 있게 도출함.
 3점 — 분수로 옳게 나타냈으나 각 단계의 이유 설명이 다소 미흡함.
 2점 — 공식을 적용하여 답만 구하고 과정에 대한 설명이 없음.
 1점 — 과정에 오류가 있으나 10의 거듭제곱을 이용하려는 시도가 드러남.
 0점 — 무응답 또는 그 외 오답

[평가요소 3] (3점)
 3점 — '모든 유리수는 유한소수 또는 순환소수이다'와 '모든 유한소수·순환소수는
        유리수이다'의 두 방향을 각각 근거를 들어 서술하고, 둘이 함께 성립함을 밝힘.
 2점 — 두 방향 중 한 방향만 근거를 들어 서술함.
 1점 — 관계를 언급했으나 근거 없이 결론만 진술함.
 0점 — 무응답 또는 그 외 오답

※ 완전한 답이 아니더라도 부분적으로 올바른 내용이나 논리를 제시한 경우 부분 점수를 부여한다.
※ 채점 유의: 직관적으로 옳은 결론을 썼더라도 그 근거에 대한 설명이 없으면 최고 급간을 주지 않는다.
```

- 마지막 유의 조항은 KICE p.56의 원문 조항("직관에 따라 옳은 관계식을 구하였더라도 그 과정에 대한 설명이 없는 경우 점수를 주지 않습니다.")을 이 단원 어법으로 옮긴 것이다.
- 5열 원표를 그대로 넣고 싶다면 〈채점 기준〉 칸 안에 **작은 표**를 삽입해도 된다. 그때의 열 순서는 [[실습5-채점기준표-예시]]의 【문항 | 평가 요소 | 채점 요소 | 수행 수준(채점기준) | 배점】을 따른다.

| 근거로 삼을 결손 | KICE 자료집에 **중학교 '수와 연산' 사례가 없다**는 점, 경기 자료집 중학교 문항 10개가 **전부 1학년 대상**이라는 점 — 즉 이 단원의 서·논술형 선행 사례 자체가 희소함 |

## Counter-Arguments and Gaps

- **압축 규칙은 도출이다.** HWPX 서식이 2칸만 제공한다는 사실은 확정이나, "평가요소 칸=명사형 어구 3~4개 / 채점기준 칸=요소별 급간 블록"이라는 배분은 원문에 명시된 규정이 아니라 실습5 5열 구조와 전북 p.32(명사형 어구)·p.72(작성 지침)로부터 **재구성한 규격**이다. 집합연수에서 강사 확인이 필요한 지점.
- **채점 요소를 평가 요소 칸에 흡수시키면 KICE의 구분(평가 요소=성취기준 분석 단계 산출 / 채점 요소=문항 개발 이후 산출, KICE p.20)이 흐려진다.** 대안은 평가 요소 칸에 `평가요소 → 채점요소` 화살표 표기를 쓰는 것이나, 칸 폭 제약이 있어 권장하지 않는다.
- 표5(집합연수 요청)에 대응하는 실습 양식이 없어 서식 규격의 근거가 가장 약하다.

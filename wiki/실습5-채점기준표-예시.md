# 실습5 채점기준표 — 컬럼 구조와 완성 예시 재현

`실습5. 채점기준표.xlsx`(시트 `고`·`중`)는 **좌우 대조형(before/after) 채점기준 개선 양식**이다. 왼쪽에 '수정 전' 완성 예시가 채워져 있고, 오른쪽 '수정 후' 블록은 문항 번호와 배점만 미리 찍힌 채 나머지가 비어 있어 참가자가 개선안을 채운다. 사전과제 표4 '채점 기준 초안' 2칸은 이 5열 표를 압축한 것이다([[사전과제-서식-작성규격]] §5-3).

---

## 1. 양식 구조 (시트 `고`·`중` 공통)

| 구분 | 셀 범위 | 내용 |
|---|---|---|
| 좌측 블록 제목 | `A1:E1` 병합 | **수정 전** |
| 우측 블록 제목 | `G1:K1` 병합 | **수정 후** |
| 헤더 행 | 2행 (좌우 동일 5열) | 아래 표 |

### 1-1. 5열 컬럼 구조 (원문 헤더 그대로)

| `A2` / `G2` | `B2` / `H2` | `C2` / `I2` | `D2` / `J2` | `E2` / `K2` |
|---|---|---|---|---|
| **문항** | **평가 요소** | **채점 요소**<br>(시트 `중`은 '채점요소' 붙여쓰기) | **수행 수준(채점기준)** | **배점** |

> 전북 연수자료 p.26·58~59·81의 표준 양식과 동일하되 **열 순서가 다르다.** 전북 슬라이드는 【문항 | 평가 요소 | 채점 요소 | **배점** | **수행 수준(채점기준)**】, 실습5 엑셀은 【문항 | 평가 요소 | 채점 요소 | **수행 수준(채점기준)** | **배점**】. 사전과제에서는 **실습5 엑셀 순서(수행 수준 → 배점)** 를 따르는 것을 권장한다(작성 시 진술을 먼저 확정하고 배점을 붙이는 순서가 자연스럽고, 실습 산출물과 대조하기 쉽다).

### 1-2. 병합 규칙

- 한 문항 블록 안에서 `문항`·`평가 요소`·`채점 요소`는 **세로 병합**, `수행 수준(채점기준)`·`배점`만 **급간 수만큼 행이 늘어난다**.
- 시트 `고`: 문항1 = **4급간**(3/2/1/0점, `A3:A6` 4행 병합), 문항2 = **5급간**(4/3/2/1/0점, `A7:A11` 5행 병합).
- 시트 `중`: 문항2 = **채점요소 3개 × 각 3급간**(2/1/0점), `A3:A11` 9행 병합, 채점요소별 `C3:C5`·`C6:C8`·`C9:C11` 병합.

| 배점 총점 | 권장 급간 수 | 실물 사례 |
|---|---|---|
| 2점 | 3급간 (2/1/0) | 시트 `중` 채점요소별 |
| 3점 | 4급간 (3/2/1/0) | 시트 `고` 문항 1-1 |
| 4점 | 5급간 (4/3/2/1/0) | 시트 `고` 문항 1-2 |
| 6점 | 채점요소 3개 × 3급간 | 시트 `중` 문항 2 |

## 2. 시트 `고` — 완성 예시 전문

### 2-1. 대상 문항 (임베드 이미지 `xl/media/image1.png` 전사)

> ※ 교내 카페에서는 다음과 같은 안내문을 게시했다. 두 학생의 대화를 읽고 물음에 답하시오.
>
> **Notice** — 다음 조건 중 하나 이상을 만족하는 고객님께 음료 주문시 10% 할인 혜택을 드립니다. (중복 할인 미적용)
> - ☕ 오전 10시 이전 주문 고객
> - ☕ 개인 텀블러 사용 고객
> - ☕ 학생증 제시 고객
>
> \<학생 A\> "난 어제 카페에서 학생증을 제시해서 할인을 받았어"
> \<학생 B\> "정말? 그럼 너는 카페에서 <u>음료 할인은 받았지만 텀블러는 사용하지 않았구나</u>"
>
> **1-1.** 학생 B의 밑줄 친 의견을 명제로 볼 때 이 명제의 참, 거짓을 판별하고, 그 이유를 조건과 각 조건의 진리집합의 포함 관계를 이용하여 서술하시오. **[3점]**
>
> **1-2.** 학생증을 제시하는 것은 음료 주문 시 10% 할인 받는 것의 어떤 조건(충분조건, 필요조건, 필요충분조건)에 해당하는지 쓰고, 그 이유를 조건과 각 조건의 진리집합의 포함 관계를 이용하여 서술하시오. **[4점]**

### 2-2. 채점기준표 (수정 전, `A3:E11`) — 원문 전재

| 문항 | 평가 요소 | 채점 요소 | 수행 수준(채점기준) | 배점 |
|---|---|---|---|---|
| 1 | 명제의 참, 거짓 판별하기 | 명제가 거짓임을 판별하고 그 이유를 논리적으로 설명하기 | 거짓임을 명확히 밝히고, 할인을 받는 조건(합집합)과 텀블러 사용 조건 사이의 포함 관계를 이용하여 정합성 있게 서술함. | 3점 |
| | | | 명제의 참·거짓은 맞게 판별했으나, 진리집합의 포함 관계를 이용한 설명이 부족하거나 논리적 오류가 있음. | 2점 |
| | | | 명제의 참·거짓 판별이 틀렸거나, 문제의 의도와 무관한 서술을 함. | 1점 |
| | | | 무응답 또는 그 외 오답 | 0점 |
| 2 | 충분조건과 필요조건을 진리집합의 포함관계로 판단하기 | 진리집합의 포함관계로 판단하고<br>그 이유를 논리적으로 설명하기 | 학생증 제시가 10% 할인을 받기 위한 충분조건임을 명시하고, 학생증 제시 집합이 할인 혜택 집합의 부분집합임을 논리적으로 서술한 경우 | 4점 |
| | | | 충분조건임을 맞게 제시했으나, 진리집합의 포함 관계를 기호나 문장으로 설명하는 과정이 다소 미흡한 경우 | 3점 |
| | | | 조건의 종류(충분조건)는 맞게 썼으나 이유 서술이 없거나, 반대로 필요조건 등으로 잘못 판별한 경우 | 2점 |
| | | | 답안의 내용이 부족하거나 수학적 근거를 전혀 제시하지 못한 경우 | 1점 |
| | | | 무응답 또는 그 외 오답 | 0점 |

**수정 후 영역(`G3:K11`)**: `G3`=1, `G7`=2 와 배점(`K3`~`K11` = 3/2/1/0, 4/3/2/1/0)만 미리 채워져 있고 **`H`(평가 요소)·`I`(채점 요소)·`J`(수행 수준)은 전부 공란** — 참가자가 개선안을 직접 쓰는 칸이다.

### 2-3. 이 예시에서 읽어야 할 설계 원리

| 원리 | 근거 |
|---|---|
| 급간은 **논리적 완성도의 단계**로 하강한다: 완전한 논증 → 논증 미흡 → 판별만 → 무관/무응답 | 전북 p.81 구조 포인트 |
| 최고 급간에는 **발문이 지정한 근거 도구**(진리집합의 포함 관계)가 그대로 등장한다 | 발문 ↔ 채점기준 연동, 전북 p.52·71 |
| 문항 1-2는 1점 급간에 "답안의 내용이 부족하거나 수학적 근거를 전혀 제시하지 못한 경우"를 두어 **0점과 구별**한다 | 포괄성 확보 |
| 문항 1(3점)과 문항 2(4점)의 급간 수가 다르다 — 배점이 클수록 급간을 늘린다 | §1-2 |
| 문형이 시트 `고`에서는 "~한 경우"(문항2), "~함."(문항1)으로 **혼재**한다 | 원문 그대로. 사전과제에서는 **"~함."으로 통일**할 것을 권장 |

### 3-3. 이 예시에서 읽어야 할 설계 원리

| 원리 | 설명 |
|---|---|
| **하나의 평가 요소 아래 채점 요소 3개** | 평가 요소('실생활 자료 분석하기')는 성취기준에서, 채점 요소 3개(해석/추론/제안)는 **발문의 반응지시어 3종에서 그대로 도출**됨 — 해석하고 · 추론하시오 · 제안하시오 |
| **반응지시어 = 채점 요소** | 발문에 지시어를 3개 쓰면 채점 요소도 3개가 된다. 사전과제 평가 요소 칸을 3~4개로 잡는 근거 |
| **OR 진술 활용** | 1점 급간에 "…없음. **또는** …임."을 넣어 서로 다른 결손 경로를 한 급간에 포괄 → 포괄성 확보의 실용 기법 |
| **0점 진술 반복** | 채점 요소마다 "무응답 또는 그 외 오답" 급간을 **각각** 둔다(문항 전체에 하나가 아님) |
| **균등 배점** | 세 채점 요소 모두 2점 — 중요도 차이가 없다고 판단한 경우의 처리. 차등을 두려면 전북 p.72 ④("더 중요하고 어려운 채점기준에 높은 배점") 근거를 밝힐 것 |

## 4. 채점기준 진술문의 문형 규칙 (두 시트에서 추출)

| 위치 | 문형 | 실물 |
|---|---|---|
| **만점 급간** | "~을 (타당하게/논리적으로/정합성 있게) 해석함/서술함/제안함." | "시기별 변화 추세를 **타당하게 해석함.**" |
| **중간 급간(설명 결손)** | "~는 맞게 판별했으나, ~설명이 부족하거나 논리적 오류가 있음." | 시트 `고` 2점 급간 |
| **중간 급간(OR 병기)** | "~는 타당하나 ~에 대한 설명이 없음. **또는** ~했으나 ~이 비현실적임." | 시트 `중` 1점 급간 |
| **하위 급간** | "~이 틀렸거나, 문제의 의도와 무관한 서술을 함." | 시트 `고` 1점 급간 |
| **최하 급간** | **"무응답 또는 그 외 오답"** — 두 시트 모두 고정 문구 | 전 블록 |
| **배점 표기** | 항상 **`n점` 문자열**(숫자값 아님) | 전 셀 |
| **종결** | "~함." (관찰 사실 기술체) | KICE p.21 문체 규칙과 일치 |

### 4-1. 확장 문형 코퍼스 (KICE 자료집에서 차용 가능)

| 목적 | 문형 |
|---|---|
| 중간 척도(설명 결손) | "…을 찾아서 **그 이유를 설명하지 못했지만**, …함." |
| 하위 척도(설명 부정확) | "…을 **찾았지만, 그 이유를 다소 부정확하게 설명함.**" |
| 체크리스트 개수형 | "**위 N가지 수행 특성 중 M가지만 만족함.**" |
| 복수 경로 인정 | "**경우1** … / **경우2** …" |
| 증명 vs 주장 구분 | "…임을 **보임.**" ↔ "… **증명 없이 제시**하고, …임을 **주장**함." |
| 인정답안 조항 | "… 경우 해당 성취기준별 성취수준에 도달했다고 판단할 수 있으므로 **정답으로 인정합니다.**" |
| 무득점 조항 | "**직관에 따라 옳은 관계식을 구하였더라도 그 과정에 대한 설명이 없는 경우 점수를 주지 않습니다.**" |
| 근거 지정 조항 | "…를 **각각 ○○에 근거하여 설명할 때만** 설명에 대한 점수를 부여할 수 있습니다." |

> 개수형("N가지 중 M가지만 만족함")은 편리하지만 **단독 사용은 포괄성 위반**이다. 전북 p.77의 실패 사례("예시 3가지=5점, 2가지=4점, 1가지=3점, 설명 못함=2점")처럼 개수만으로 급간을 나누고 최하 수준에도 점수를 주는 기준표는 검토에서 반려된다. 개수 기준을 쓰려면 **각 항목의 질적 요건을 함께 명시**할 것.

## 5. 검토(정교화) 기준 — 실습5 '수정 후' 칸을 채울 때의 점검표

전북 p.73~77의 검토 항목. 사전과제 채점 기준 초안의 자기 검토에도 그대로 쓴다.

| 기준 | 점검 질문 | 실패 사례(원문) |
|---|---|---|
| **타당성** | 평가 요소 추출이 성취기준에 기반하는가? 세부 내용이 평가 요소에 근거해 수행 수준을 구별하는가? | — |
| **배점** | 평가 요소별 비중을 고려한 배점인가? 급간·부분 점수의 근거가 진술에 충분히 반영되어 수행수준 구분이 명료한가? | — |
| **배타성** | 급간·채점 요소 진술이 서로 겹치지 않는가? | 채점요소 '구조의 명확성'과 '구조의 논리성'의 수행수준 진술이 서로 겹침 (p.76) |
| **포괄성** | 평가하고자 하는 능력을 빠짐없이 포함하는가? 어떤 답안이든 어느 급간엔가 들어가는가? | 개수 세기만으로 급간을 나눈 기준표 (p.77) |
| **명확성** | 복수 교사가 동일 기준표로 채점 시 비슷한 결과가 나오는가? 수행수준별 답안 예시를 제시할 수 있는가? | — |
| **실용성** | 교사·학생이 이해·활용하기 쉬운가? 향상 피드백을 줄 수 있는가? | — |
| **문항 기술** | 어휘 적합성, 편파성 없음, 학생 가치를 판단하지 않는 진술, 맞춤법 | — |

**작성 지침 6개(전북 p.72 원문)**
1. 누가 채점하더라도 **일관성** 있게 채점하도록 채점기준과 부분 점수별 예시답안이 **구체적**이고 상세해야 함.
2. 학생의 어떤 답안이라도 각 배점 구간에 포함되도록 **포괄적**으로 기술.
3. 각 배점의 채점기준은 모든 영역을 포괄하되 서로 겹치지 않게 **상호 배타적**으로 기술.
4. 더 중요하고 어려운 채점기준에 높은 배점을 부여하되, 단지 어렵다는 이유로 중요하지 않은 내용을 강조하지 말 것.
5. 사고력·표현력·이해도를 평가하는 채점 요소라면 필체·띄어쓰기·철자 등 단순 실수에 과한 감점을 하지 말 것.
6. 출제 의도가 명확히 전달되어야 할 경우 **'채점 유의 사항'**을 추가할 수 있음.

**추가 쟁점(전북 p.82)**: 전체적으로 수준 높은 답안이 부분 부족으로 감점되는 경우 / 채점 요소별 배점이 적어 수행 수준 차이를 반영하기 어려운 경우 / 형식적 요소의 반영 / **'정도 부사어'(대체로, 다소)** 사용.

## 6. 채점기준표 4유형 — 사전과제에서 무엇을 쓸 것인가

| 유형 | 정의 | 장점 | 단점 |
|---|---|---|---|
| 일반적 | 유사 과제들에 하나의 기준표 | 과제 간 일반화, 학생에게 사전 제공 가능(자기평가), 지속 활용 | 채점자 간 일치도 낮을 수 있음, 숙련 필요 |
| **과업 특수적** | 하나의 과제 전용 | 채점 쉬움, 채점자 간 일치도 높음, 구체적·즉각적 피드백 | 정답 노출로 사전 제공 불가, 개발 부담, 예상 밖 정답 누락 |
| **분석적** | 단계·요소마다 점수 할당 후 합산 | 기준 명료, 범주별 가중치, 강약점 피드백 | 구조 복잡, 채점 시간 소요 |
| 총체적 | 답안 전체에 하나의 점수 | 신속, 채점자 간 신뢰도 비교적 높음 | 채점자마다 다른 준거 적용 위험 |

> 실습5의 두 예시는 모두 **과업 특수적 + 분석적** 채점기준표다. 사전과제에서 유형을 밝힐 때는 **"과업 특수적·분석적 채점기준표"** 라고 명명하는 것이 정확하다.

## 8. 참고 — 수행평가로 확장할 때의 4단 척도

## Counter-Arguments and Gaps

- **열 순서가 자료마다 다르다**(전북 슬라이드 = 배점 먼저 / 실습5 엑셀 = 수행 수준 먼저). 사전과제에서 어느 쪽을 따를지는 집합연수에서 확인이 필요하다.
- 시트 `고`는 문형이 "~함."과 "~한 경우"로 혼재한다. 원문의 흠결이며 그대로 모방하지 말 것.
- **'수정 후' 블록은 두 시트 모두 비어 있다.** 즉 "개선된 채점기준표의 정답"은 원자료에 존재하지 않는다. §7은 도출이다.
- 시트 `중`의 문항 2는 세 채점 요소 배점이 모두 2점으로 균등하다. 실제로는 '히스토그램 해석'(자료 읽기)과 '실천방안 제시'(가치·태도)의 인지 부담이 다른데 동일 배점을 부여한 것이므로, 전북 p.72 ④의 중요도 기반 배점 원칙과 긴장 관계에 있다.

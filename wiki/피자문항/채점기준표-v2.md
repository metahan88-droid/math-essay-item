# 채점기준표 v2 — 급간별 행 분리 + 배타성·포괄성 (2026-07-31)

연수 자료 채점기준표 예시(문항 | 평가요소(채점요소) | 배점 | 수행 특성) 이미지를 기준으로 재설계.

## 구조 변경 — 급간 1개 = 표 1행
기존: 한 채점 요소의 급간 진술이 한 셀에 뭉쳐 있었음.
v2: **점수 급간마다 별도의 표 행**. 문항 열은 그 문항의 모든 급간 행에 걸쳐 세로 병합(rowSpan 5/5/8/6), 평가요소(채점요소) 열은 각 채점 요소의 급간 행에 걸쳐 병합(rowSpan 3 또는 2), 배점 열에는 2·1·0이 한 칸에 하나씩.
- 표 규모: 헤더 1 + 데이터 26행(문항1 5, 문항2 5, 문항3 8, 문항4 6, 공통 1, 합계 1).
- 빌더: `build_rubric_v2()` — rows 명세(item/elem/score/desc)에서 연속 동일값을 rowSpan으로 묶고 셀·행 높이를 산출. 표는 헤더 텍스트("수행 특성"+"평가요소")로 찾는다(인덱스는 편집 중 변동).
- 버그 수정: 데이터 행의 rowAddr이 헤더(0)와 겹쳐 cellAddr 중복이 나던 것을 r+1로 교정.

## 배타성·포괄성
급간을 **옳게 수행한 하위 요건의 개수**로 가른다.
· 최고점 — 하위 요건 ⑴⑵⑶을 모두 옳게 수행한 경우
· 중간점 — ⑴부터 ⑶까지 가운데 한 가지 또는 두 가지를 옳게 수행한 경우
· 0점 — 옳게 수행한 것이 없거나 무응답인 경우
어떤 답안도 개수가 하나로 정해지므로 정확히 한 급간에만 걸리고(배타성), 0~n의 모든 개수가 덮인다(포괄성). "또는"으로 이질적 결함을 나열하던 종전 방식과 그로 인한 급간 공백·중복이 구조적으로 사라짐.

검증 에이전트가 요소별 충족 벡터를 2^n 전수 열거해 중복 0·누락 0을 확인했고, 두 문서 모두 차단 지적을 받아 다음을 반영:
- 카운트를 정하는 규칙이 급간마다 흩어져 어긋나던 문제 → 규칙은 공통 행과 최고 급간으로 올리고 하위 급간에는 개수 범위만 남김.
- 결합형 하위 요건(값+비 등)의 부분 수행 처리 총칙 신설("요건에 적힌 내용을 모두 옳게 수행한 경우에만 센다").
- 원본 원칙 6 후단(수 산출 자체가 요건인 항목 목록) 복원.
- 모호어 "미흡" 제거, 0점 급간을 침범하던 예시문 교정.
- 추가문항: 문항 2를 원본 구획(요소1 산출 / 요소2 ㉡ 반박)으로 되돌려 다른 문서의 참조와 정합.

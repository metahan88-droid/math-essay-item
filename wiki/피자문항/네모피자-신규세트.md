# 신규 세트 「네모 피자 신메뉴 검수단」 (2026-07-30)

닮음비를 '찾는' 과정을 문항 1에 담은 추가 세트(문항 1~4, 3+3+5+4=15점). 검증 2렌즈 통과(차단 0), 수치 110여 체크 전부 PASS.

## 설계
- **실측→판별→닮음비**: 상자 4종 실측(스몰 21×21×3, 미들 28×28×4, 빅 35×35×5 → 3:4:5 / 라지팩 45×30×5 → 9:7·6:7·1:1 비 불일정 → 닮음 아님 반례).
- 정사각형 피자라 π 불필요: 넓이 441/784/1225(9:16:25), 부피 661.5/1568/3062.5(27:64:125), 치즈 90/160/250g(1g당 4.9cm²).
- 의사결정: 예산 35,000원, 1인분 392cm³, 8명 3136cm³. ⓐ 미들 2판(32,000원·정확히 8인분·10.2원/cm³) / ⓑ 빅 1판(25,000원·최저 단가 8.2원인데 73.5cm³ 부족) / ⓒ 빅+스몰(34,000원·9.5인분·9.1원) → 결론 ⓒ. 어느 지표(1cm³당·10,000원당)로도 동일.
- 문항 4: 16명분 6272cm³ → 빅 2.048판(2판은 147cm³ 부족) → 3판·치즈 750g / 파티팩: 치즈 810g·두께 1.5cm 고정 → 넓이 3969=스몰 9배 → k²=9 → 한 변 63cm (완전 닮음이면 k³=9 세제곱근 → 회피 설계).
- 채점기준: 처음부터 수준 기술식(9개 채점 요소).

## Codex 리뷰 반영 (2026-07-30 심야)
**A급 치명 1건(수학 논리)** — 문서가 "두께를 고정했으므로 넓이의 비만으로 한 변을 구할 수 있다"고 잘못 인과화했음. 실제로 한 변 63 cm는 치즈 810 g → 넓이 3969 cm² → 63×63으로 **두께와 무관하게** 정해지고, 두께 조건이 바꾸는 것은 부피(두께도 3배면 27배 / 고정하면 9배)임. 발문·예시답안·채점기준·출제 의도·성취수준·차시 평가란을 모두 올바른 인과로 재작성.
그 외: 라지팩 판별의 발문·조건·채점 불일치 해소(서로 다른 비 2개 이상 수로 제시 요구, 3:2 vs 1:1 경로도 인정), D-4①의 ㉠ 동조 처리를 "요소 전체 0점"에서 "㉠ 반박 하위요건만 불인정, 판단 옳으면 1점"으로, D-4②에 대소 역전 시 절차 인정 규정 추가, 조합 방안 ⓒ의 단가를 "합산 금액÷합산 부피"로 조건에 명시하고 단순 평균 오답 처리 규정(D-4-1) 신설, 동치 단위율(1,000원당 등) 인정, 용어 요건에 동치 표현 허용, 직육면체 전제 명시, "모든 산출값 유한소수" 서술 정정, 조건⑤ 둘째 문단 어순(필요량 미달 제외 먼저) 정정.

# 채점기준 수준 기술식 전환 (2026-07-30)

연수 자료 표준 양식(문항→평가 요소→채점 요소→배점→수행 수준) 반영: "충족 개수형" 체크리스트를 **채점 요소별 배점 급간마다 수행 수준을 질적으로 진술**하는 방식으로 전면 전환.

## 구조
- 문항 1 [3점] = 산출(2: 2/1/0) + 관계 서술(1: 1/0)
- 문항 2 [3점] = 개수 산출·㉡ 반박(2) + 1개당 넓이 비교(1)
- 문항 3 [5점] = 산출·두 단계 판단(2) + ㉠ 반박(2) + 공지문 조직(1)
- 문항 4 [4점] = ㉮ 판 수·총 개수(2) + ㉯ 조건 구분·지름(2)
- 0점 통일: "무응답 또는 그 외의 오답." / 기존 (가)~(마) 규정(동등 경로·용어 요건·병기·반올림 관용)은 급간 진술과 공통 기준(원칙 1~11 재편)에 손실 없이 흡수. 기계 검증: 발문·조건·답안 불변, 개수형 어휘·옛 요소 참조 0건, 수치 신규 0건.
- 검증 에이전트 2건이 세션 한도로 실패 → 인라인 기계 검증 + Codex 리뷰로 대체.

## 워크북 정합 (핵심 3건 직접 반영)
3차시 조작적 정의→채점 요소의 뿌리 문장, 5차시 목표→급간 진술 연결 심화, 6차시 수준 진술식 평가 성찰 추가.
관련: [[4문항-재구성]], [[네모피자-신규세트]]

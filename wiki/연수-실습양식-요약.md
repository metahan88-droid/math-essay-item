## 2. Key Points — 실습 양식이 규정하는 것

1. **문항 제작 5단계 절차**(전북 p.28): ① 성취기준 및 성취수준 확인 → ② 평가 요소 선정 → ③ 평가 방법 선택 → ④ 문항 작성 → ⑤ 수행 수준(채점 기준) 작성. 실습 1·2·3·5가 이 순서에 1:1로 대응한다.
2. **실습1 = 성취기준 4단계 분해 활동**: 색칠 → 3범주 정리 → 위계 분석 → 평가요소·평가방법 도출. → [[성취기준-분석-양식]]
3. **실습3 = 반응지시어 검토·수정**: 17종 사전 검토 → 5항목 카드로 정의 보완 → 실제 발문 수정. 수학과 반응지시어 7종(계산/구하다/서술/판단/설명/논술/해석)의 정의·도식·답안 예시가 별도 이미지로 제공됨. → [[반응지시어-수정사례]]
4. **실습5 = 채점기준표 좌우 대조형(수정 전/수정 후) 5열 양식**: 【문항 | 평가 요소 | 채점 요소 | 수행 수준(채점기준) | 배점】. 0점 진술은 "무응답 또는 그 외 오답"으로 고정. → [[실습5-채점기준표-예시]]
5. **실습2 = 단원설계·평가설계**: 수행평가로 확장할 때만 사용. 척도는 A~E가 아닌 **탁월/우수/보통/초보** 4단, 열 구조는 【평가 요소 | 척도 | 기대 수행】.
6. **개념기반 매핑 시트 `교육과정 매핑(2월-중2)` 2행이 [유리수와 순환소수]의 원본 레코드**다: 성취기준 [9수01-06], 지식/이해=유리수와 순환소수, 기능/과정=유리수와 순환소수의 관계 설명하기, 가치/태도=수 체계의 논리적 아름다움에 대한 관심, 개념 렌즈=체계·구조, 주도 개념=표현·관계, 포괄적 일반화=수체계는 연산의 일관성을 지키며 확장된다, 총괄 평가=입학사정관 구술평가.
7. **사전과제 서식과의 대응**은 §5의 표로 확정된다. 서식 자체의 칸별 작성 규격은 [[사전과제-서식-작성규격]], 분석 칸의 관점은 [[기존문항-분석-관점]].

## 4. 핵심 원문 인용 (규격 계열)

| 항목 | 원문 | 근거 |
|---|---|---|
| 반응 지시어 정의 | "학생이 답을 어떻게 써야 할 것인가를 지시하는 동사" | 전북 p.44 / 경기 p.9 |
| 평가 요소 정의 | "'성취기준 도달의 증거'로 학생들이 보여주기를 기대하는 핵심 내용을 '구체적으로 기술'한 평가 내용, 관찰 가능한 행동 중심으로 서술" | 전북 p.39 |
| 평가 요소의 형태 | "학생이 주도적으로 반응할 수 있는 지시어를 '**명사형 어구**'로 사용" (예: 그래프 해석하기, 관계식 구하기, 두 변수의 관계 설명하기) | 전북 p.32 |
| 채점 요소 정의 | "학생의 수행 결과를 평가할 때 무엇을 어떻게 평가할지를 구체적으로 제시한 기준… 평가 요소를 바탕으로 하되, 문항에서 추가적으로 제시한 〈조건〉 등을 고려하여 구체적으로 제시" | 전북 p.25·59 각주 |
| 평가요소 ↔ 채점요소 시점 차 | "평가 요소는 성취기준 분석 단계에서 도출되지만, **채점 요소는 문항을 개발한 이후에** 구체적으로 기술이 가능" | KICE p.20 |
| 채점기준표 정의 | "평가 과제에 대한 학생들의 성취 정도를 질적으로 평가할 수 있도록 성취수준을 참고하여 작성한 것. 평가 요소별 수행 수준(채점기준)을 구체적인 언어로 진술한 것." | 전북 p.58 |
| 문항 구조식 | **자료(보기) + 발문[평가 요소 + 반응 지시어] + 조건** | 전북 p.52 (박혜영 외 2019) |
| 조건 ↔ 채점기준 | "'발문'에서 학생들에게 요구하는 반응 지시어와 문항의 '조건'은 수행수준(채점 기준)에 반영" | 전북 p.52 |
| 신뢰도·공정성 | 정확한 수행수준 마련 → **신뢰도** / 문항 〈조건〉의 제한 요소를 수행수준에 포함 → **공정성** | 전북 p.71 |
| 난이도 목표 | "각 수준에 해당하는 학생 1/2이(또는 2/3이) 만점을 받을 수 있도록 개발" | 전북 p.41 |
| 부분점수 원칙 | "완전한 답이 아니더라도 부분적으로 올바른 내용이나 논리를 제시할 경우 부분 점수를 부여함" | 전북 p.80 |
| 서술형 ↔ 논술형 | 서술형=정의·설명·요약·비교·대조·분석·풀이 과정 서술 / 논술형=종합·비평·정당화·해결 방안 제안·근거를 들어 논증 | 전북 p.16 |
| 채점기준표 유형 | 실습5의 두 예시는 **과업 특수적 + 분석적** | 전북 p.60~70 |
| 마무리 인용 | 데이비드 산다 [개념기반수학] — "그들의 얼굴에서 보이는 그 '아~하' 순간들, 그것이 우리를 교사로 만든다." | 전북 p.85 |

## Counter-Arguments and Gaps

- 채점기준표 **열 순서**가 전북 슬라이드(배점 → 수행 수준)와 실습5 엑셀(수행 수준 → 배점)에서 다르다.
- 3범주 **표기 방식**이 양식마다 다르다: 단원설계·성취수준 자료는 `지식·이해 / 과정·기능 / 가치·태도`, 매핑 시트는 `지식/이해 · 기능/과정 · 가치/태도`.
- 실습 산출물 다수가 미작성이어서(§3) '좋은 예'의 표본 수가 적다. 특히 **개선된 발문·개선된 채점기준표의 모범답안이 원자료에 없다.**
- KICE 자료집에는 **중학교 '수와 연산' 사례가 없고**, 경기 자료집의 중학교 문항 10개는 **전부 1학년 대상**이다. 즉 [유리수와 순환소수] 서·논술형의 선행 사례 자체가 희소하다.
